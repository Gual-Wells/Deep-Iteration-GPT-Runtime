# Under the Work Light / 工作灯下

原创虚构的暑期样机助理面谈，主要服务工程／端侧AI实习面试交流。场景在制作流动展具的小工作室：面谈者偏现场制作，候选人用旧手机工具盘原型说明自己的工作。这与算法研究岗的深度技术面谈有真实差别，不能替代全部面试准备。

**手机只需[PHONE.txt](edition/phone/PHONE.txt)**：自足的多角色跟听指引和公开预印本。也可直接读 [LISTEN.md](edition/phone/LISTEN.md)，结束后另看[公开语言回看](edition/phone/PUBLIC-REVIEW.md)。不要求听者接手、回答或回传。

[创作者版](edition/CREATOR.md)单独放在手机目录之外，包含人物内心往返、世界提案/处理、原始源快照。默认跟听时不带它。

生成时，Mara 与 Gus 各有独立外显和伴生内心上下文，两个独立世界作者从创世活动；后一个角色真正收到前一个角色已提交的输入。公开记录保留原话和顺序。录用没有发生：故事选在进入后续实操与商定时间处结束，设备详情、充电和跨机运行仍是未来事项。

来源入口：[原始快照](source/preprint.json)、[原生来源映射](source/native-source-manifest.json)。`preprint audit-sources` 可在原临时目录离线时检查归档；当前没有缺失的事件输入引用。原始记录用 `.raw` 保留字节，输入文件摘要只证明材料一致，不是模型身份、真实岗位或真实设备测试认证。

所有人物、项目经历与数字都是虚构，不能当作用户履历。相机预览/分析变换及性能测量的背景参考 [Android 官方文档](https://developer.android.com/media/camera/camerax/transform-output)与 [LiteRT 官方说明](https://developers.google.com/edge/litert/next/benchmark)。Mara 的具体修复是角色自述，不是唯一正确的通用实现；一次匹配不证明可靠性。

已做公开来源核对和独立新上下文的文字跟听演绎。真实手机 Voice、音色、实时语流与学习收益尚未验证。
