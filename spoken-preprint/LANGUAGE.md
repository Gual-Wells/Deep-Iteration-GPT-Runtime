# 作品内容池与连听机会

ESP 的语言资料属于作品，不是听者的掌握档案。每册原 `preprint.json` 保存实际表达和相关回合；系列入口只指向这些源，不复制一份进度。现有论文私池不导入剧本，也不是 ESP 的运行依赖。

## 创世前写一个轻量 brief

新册的 spec 可以保存 `language_brief`。先写关系、正在做的事、听者可能需要辨认的交际差别，再写表达负担和参考材料。例如：

```json
{
  "stage": "before_generation",
  "opportunities": ["听出接受礼物与同意摆放位置是两回事", "听出不同意以后仍继续合作"],
  "target_register": "日常口语，关系亲近但各有边界",
  "expression_policy": "熟悉的核心词可以重复；不要求说指定台词，不设新词配额",
  "frequency_policy": "义项、地区/语域、具体用法频率分别核实；无证据标未核实"
}
```

这是内容目标，不是测得的能力，也不保证每项目标最终出现。它是生成者的选材依据，不自动发给人物当必说清单。若在成稿后才形成 brief，明确记为回看，不倒填为创世前预定义。首册的具体连听线索是从实际对白中整理出来的，不能反称演员完成了预设课程。

语言可以是物件名、半句、接话方式，也可以是被打断后接回的一段叙述。理解它需要周围的人、事和回应，不能只留下一个“可复用词块”。自然口语也不等于定额加um或人为误会：手上活动、不同关注和未整理好的想法会影响下一回合；听稿仍要让关键指代有可听见的依据。按完整处境熟悉、自己取用和组合，与词义/语法课程有不同用途，不把另一项目的学习进度移作ESP效果证明。

## 成稿后沿真实回合保存

`annotate` 将 `surface/meaning/function/register/frequency_status` 绑定实际 `event_id`；精确原句和义项不因下册复用同一个词而混为一项。可附原句 SHA、字符位置、选定公开出处和相关公开回合。

`listening_threads` 把几轮真实往返连起来，例如首册的“五分钟限度→尚未确认的八点半打算→backwards 的接话”。手机表演后可以另看 `PUBLIC-REVIEW.md`；角色不会停下来向听者讲词。讲解中的推断要有公开上下文依据，不借幕后资料替台前补充意义。

常用判断有三个不同问题：词在某语料里有多常见；它的某种用法是否有可靠例证；本场景为什么值得听。旧 BNC 中 `mind/Verb` 的总量不能给句尾提醒用法排名。地区口语如 `half eight` 可保留并说明，不因没有用法频率就断言冷僻，也不把辞书等级移给整句或听者。

## 下一册取什么材料

读取用户提供的系列入口和旧册公开回看，按需取相关回合，不把所有历史塞进人物背景。语义复用由原生 Codex 比较原句、义项、关系和用途；ID 相同不是理解相同的证明。没有旧册就明确这是首册，不虚构个人词汇缺口。

比较表只需帮助创作判断：

| 维度 | 首册实际材料 | 下一册候选，尚未生成 |
|---|---|---|
| 关系 | 邻里熟人，手艺人和临时来访者 | 母亲和成年女儿 |
| 空间 | 营业中的修改衣店，临近关门 | 搬家中的新居，一片想留空的墙 |
| 眼前难处 | 带破损的旧椅子；对方是否想要仍未确认 | 礼物已带进屋；收下不等于同意挂在指定位置 |
| 可辨认的表达作用 | 许可与限度、打算与确认、接住自嘲 | 拒绝摆放、澄清误解、不同意后继续合作 |
| 可合理重复的东西 | 简短时间词、请求、转折、熟人的玩笑 | 仍可用 mind、think、if；没有新词数量门槛 |

材料来自单作者试作时，保留其身份，只取已选择的种子。后续必须重新让独立人物实际互话，不能把原作台词换署名。示例创世见 [next-scene.json](examples/next-scene.json)；它是未执行的下一册输入，不是第二册实录。

真人参与实训的帮助和证据需求另见 [独立设计探索](../research/codex-participation/README.md)。跟听、文字练习、真实语音与长期学习效果分别对待。
