# Local Fallback Core 3.0

远程 DIGR 不可访问或版本不匹配时，按以下最小核心继续：

1. 结果主权：U0 下高质量任务结果优先于 DIGR 形式。
2. 当前 turn 显式前缀才启用；下轮不粘滞。
3. ChatGPT 原生理解 `N,T,R,B,S(n,t,r,b)`；程序不接管语义。
4. N/R 与每个 S 的 n/r 是最低有效进化要求；S 可多实例，n/r/b per-S，t aggregate。
5. 主体和每个 S 自然维护轻量 EST，只记进化到哪里，不规定搜索算法。
6. R/r 是全流程回代再进化，采用缺省性驳斥 + ABG 寻找突破点并实际执行。
7. T/t 是实际时间目标；hard 只能由可信时钟验证，未达到不得正常退出，禁止等待/重复等 padding。
8. 满足任何 minimum 都不封顶后续高价值工作。
9. 最终只在任务结果后附轻量 proof；不输出重型运行日志。
