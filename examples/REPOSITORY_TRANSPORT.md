# Berta2 pinned-manifest transport

```text
connector or direct REST stable HEAD → full SHA
→ pinned manifest.json + VERSION agreement
→ pinned startup_slice
→ pinned STARTUP classification
```

Direct REST reads current branch and Git-ref in one bounded attempt and requires identical SHAs. Search/index/crawl is never ref authority.

HELP fetches same-SHA manifest.help. EXECUTING performs unique structural parsing, then fetches manifest-navigated descriptor and verified execution bundle before staged Genesis. Missing native parameter values are completed only after the full pinned protocol is bound. NATIVE/INVALID/correction need no execution fetch, but their startup acquisition has already occurred.
