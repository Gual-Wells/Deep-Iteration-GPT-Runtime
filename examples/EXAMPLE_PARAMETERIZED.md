# Parameterized

```text
深度迭代（3，15m，2，hard，S（2，6m，1，hard））：深度分析任务 X
```

Interpretation:
- main N >= 3
- main R >= 2
- total trusted elapsed >= 15m before normal stop
- any number of S instances may occur
- each actual S: n>=2, r>=1, b=hard
- union of all source-active intervals >=6m
- meeting minima never prevents further high-value work
