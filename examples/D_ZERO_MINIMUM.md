# D zero minimum does not disable D

`DIGR（D（0））：任务`

The frozen contract requires zero completed D interventions, but D remains available to native intelligence when a disruptive non-local intervention can materially improve the result. `D_actual` may therefore be 0, 1, 2, ... while still satisfying the minimum.

L is not public in Alpha 8. Any D that actually runs still uses the internal L1 isolation invariant and must complete execution, result production and reintegration before it counts.
