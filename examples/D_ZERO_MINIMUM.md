# D zero minimum does not disable D

`DIGR（D（0），L（1））：任务`

The frozen contract requires zero completed D interventions, but D remains available to native intelligence when a disruptive non-local intervention can materially improve the result. `D_actual` may therefore be 0, 1, 2, ... while still satisfying the minimum.

L remains `target/capability/actual`. If no D completes, there is no completed-intervention L stop gate and L actual may remain `?`. If D completes, every counted intervention must carry its actual IsolationReceipt and normal L mismatch rules apply regardless of the zero target.
