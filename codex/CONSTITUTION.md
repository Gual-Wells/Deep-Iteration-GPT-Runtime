# DIGR 原语宪法

这四条约束本发布 pin 下的全部 DIGR 执行、协作和交付，也约束 DIGR 自身的更新。各机构在自己的正常入口落实它们。

1. **证据与主张相称。** 分析由充分前提、推论和能改变判断的反例成立。经验缺口只约束依赖它的主张。工程和成品按实际使用路径检查；必要验证针对具体行为与故障。详见 [METHOD](METHOD.md) 与 [PERMISSIONS](PERMISSIONS.md)。
2. **决定和执行各有来源。** 当前用户决定、原件事实、真实权限、角色和费用各以相应来源为准。派发、收到、裁决、落实和交付按实际发生登记；一项记录只证明它能证明的事实。详见 [PROTOCOL](PROTOCOL.md)、[PERMISSIONS](PERMISSIONS.md)、[LIVE](LIVE.md) 与 [RETURN](RETURN.md)。
3. **更新延续稳定性。** 已冻结的任务沿完整原 pin 恢复。新 pin 只在声明的范围内变更语义，保留其余路径及既有授权、停止和恢复边界。
4. **更新充分实现委托。** 发布同时满足稳定延续与要求覆盖。每项要求应在正常入口达到实际结果，失败与恢复也按真实状态处理。发布前核对旧 pin 的恢复、新 pin 的相邻路径及新增行为的完整因果链。有实际冲突时，优先用版本化适配解决；仍需改变委托的取舍由用户决定。
