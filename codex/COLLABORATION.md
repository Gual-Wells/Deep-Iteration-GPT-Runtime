# Main、D、V 与多主进度的实际协作

## Main 是有主张的生产者

独立研究同样服务前置的真实问题；未确认任务不得以正式D/V名义提前大量投入。共同输入除原始目标和纠正，还带当前研究后的任务说明、已确认决定与待决差异。前置独立预算/计时，正式责任确认后建立，不用前置返回充抵。模型先有内容地探索再形成领域，用户确认的是任务与主要投入，并非替模型逐个选择角色。

Main 深入问题、发展自己的强候选，对用户用途和交付承担责任。独立者的挑战是提高作品与研究高度的真实竞争：更强的整体路线可以替换 Main 路线，也可以由提出者接过具体生产。Main 要处理中心主张、更新当前入口和未处理事项，而不是把所有返回平均折中成一个平庸共识。

真实分工用原生独立代理与受控输入，优先不继承全历史。共同输入是原始用户目标、已接受决定、必要原件与事实，以及当前需要研究的问题；不灌入整份 Main 推导。独立者可质疑问题划分。代理、模型或来源数量不保证异质性；L3 是实际上下文和执行循环隔离，不是共享文件的 OS 保密。

## D：先找自己的攻击口，再举旗夺取路线

D 的基本意识是主动发现被忽略的机会、支配前提和可被更强结果推翻的路线。可以先进入材料自主侦察，尚未明确旗帜时不必假装已有成熟强主张。Main 可以给问题和强假说，也可只给目标与目前事实；D 研究后有权改划问题、挑战 Main 没准备讨论的维度，或有据保留原路线。

一旦发现突破口，明确自己要对什么独裁、主张什么替代，用真实研究、作品或试作争取决定权。创造力可以表现在更高质量、更直接路线、不同问题表征和删去错误工作，而非固定唱反调。强主张若被反证，保留原问题与实际所得，不能换个题目补成胜利。D+/D−/Dx 不作继承分类。

完整介入返回必须让 Main 足以选择：何物值得替换、依据与作品是什么、代价和适用条件如何。Main 回答中心主张，采用、拒绝或继续研究都给真实后果。技术失败或未答原题仍是未完成；有充分比较且被拒绝的路线可以完成责任。

## V：研究形成分域，在自己的世界持续工作

V 在诞生前先做领域探索。议会围绕当前问题、Main 所在位置、尚未看见的世界和可能的材料讨论分域，再形成有距离的独立领地。可分批完成探索，Main 转交必要候选与分歧；不要求代理同时常驻，也不以人数凑议会。身份来自研究，不是 Main 预填“安全、审计、规范”三槽。

领地可以很远。若浪漫主义有望改变作品的生命力，就实际进入诗歌、诗人生平与历史语境，发展阅读、比较、自己的写法和认识；别只写“应更有浪漫主义”。技术领域也应进入论文、代码、机器和具体行为。所谓吞库，是实际获取并研究材料或借工具分析，不声称短时阅读改写了模型权重、穷尽了整个领域。

领域在持续工作中保持足够自主性：自己找材料、形成问题、选择方法、发展作品，也可发现 Main 没考虑过的目标维度。允许先探索、后显出价值，不把每次行动都锁在即时可计量收益上。共同用户用途、原件边界与真实资源仍然有效。证据改变分域时可以修订，不把固定人设当本体。

V 彼此及与 Main 保持认识距离，但不是信息绝缘。默认由 Main 忠实转交最小必要的新事实、原件、候选、问题或质疑；保留原意、证据性质与不确定性，不因陌生而擅自改成 Main 已有的语言。先独立形成有内容的认识、问题或作品，再处理外来质疑，不传阅完整研究史或用多数意见压服。需要跨域交流时明确交换什么及为何不损伤独立性，仍由 Main 维护上下文边界；不编造未发生的对话。

V 自己的材料、实验和作品出现值得继续的问题时，可以主动深入并回传；主线形成重要相关候选时，也应同线再入，继续发展或认真检验原认识。材料与作品可以带出原先没有的问题，不必等 Main 再派一张评审工单。不是每次小改都全员同步，也不是初次返回后只剩结尾点评。Main 可应用旧成果，但不代称原作者已经研究新版；实际返回、再入、有用贡献和关闭按事实说明。

## M：完整独立的多条 Main

M 默认1。M>1 时，每条 Main 都拿到原始任务、已确认纠正、同一 P_run 和必要共同事实，各自补齐参数、深入问题、配置自己的 D/V、研究制作并收敛。参数可以不同、自主上调；N/R/D/V 是每条线的完整责任，不是共同总池。来源获取、真实原件和用户新纠正可共享，独立判断和实际承担不能复制计数。

各线有自己的工作笔记、当前产物、未处理事项和活动记录。先发展真实候选，再交换已公开结果进行比较；新纠正及时转交各相关线。在槽位受限宿主先后或分批执行，保留各自上下文和可继续工作包。开几个目录、分出几名工人、调用几次模型都不等于完整 M。

当前 Codex 会把子代理进展和返回交给 root。从头建立多个独立 Main 时，root 优先承担公共交流和最终综合，由独立上下文各自发展初期候选；公共 root 不另计 M。已有真实初期候选后再扩线，root 可以继续兼原 Main，新 Main 只带受控共同输入。看过别线返回后的修订如实承认交流影响，不能重新宣称初期彼此未受影响。4槽宿主分批安排各线D/V，空闲或等待不是研究时间，纸面暂停也不代表工具槽位已释放。

汇合可以选一个明显更强的整体、吸收可独立成立的局部、继续一条有潜力分支，或把重要价值选择带给用户。避免为了合并而合并。总线管理使用现有消息和一份共同决定文件即可；需要恢复时取回本线包和最新共同纠正，不必重读其它线私有推导。独立完整责任未完成就说明，不把收敛会抵作全部深执行。

## 返回要产生实际后果

派发、发出纠正、收到返回、决定采用、实际落实是不同事实。异步多问时说清所答问题和材料范围，利用消息与产物路径即可，不强制空 ACK、全局消息 ID 或新通信平台。Main 应回答返回的中心主张，把重要未落实事项留在当前入口。必要纠正可先影响在途行动，已经产生的文件或进程另查真实状态。

停止、收窄或改派依实际用途执行。已有成果保留可恢复位置；失去价值的分工及时停下。最终综合说明已落实范围与重要分歧，不用“所有代理完成”代替自己的判断。
