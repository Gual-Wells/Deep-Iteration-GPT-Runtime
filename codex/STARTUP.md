# DIGR Codex — 启动与恢复

本 profile 面向已选 Codex 通道。实际获取当前 `codex/codex-host-adaptation` 的完整 Git SHA，从同一 SHA 取得并核对 `codex/manifest.json`、`codex/VERSION`、startup_slice 及散列。根目录 DIGR 另有入口。薄路由仅宽捕获精确 DIGR 或深度迭代，仓库决定语义；不得从引文、历史、工具输出或界面状态重造调用。

## 选择当前路径

- 先取回未结束任务的真实 lifecycle、原 `P_run` 和待处理输入。新前缀仍须真实获取，取得的当前版本决定该条输入表面，原任务按冻结版本应用用户意图。当前输入可能改变 U0、权限或交付，也可能只是进度问答；宿主轮次或上下文压缩不会结束任务。恢复旧任务优先定位完全相同的 `version@SHA` 工具。
- 无未结束任务时，`NATIVE` 原样交回普通流程；精确 `DIGR/help` 为 `HELP`，只取 manifest.help；损坏参数或空任务为 `INVALID`，说明实际结构问题。三者不建立深执行、访时或费用权利。
- 完整结构 `DIGR(参数)：任务` 为 `EXECUTING`，包括询问或只读委托。本版正式参数组接受N/T/R/B/S(n,t,r,b)/D/V/L/M/X/F/C，其中X/C为0或1，F为非负整数；旧 `DIGR(参数)(X)：任务`、`(X=Gmail)` 兼容。重复或冲突的 X 在入口明确指出。ASCII／全角单冒号与双冒号均按任务头解释，消费完整分隔符；三枚及以上无效。保留任务原文与参数内标点。DIGRC、DIGRP 是兼容输入，边界按本版 [PROTOCOL](PROTOCOL.md) 解释。
- 精确 `DO:` 或 `DO：` 只接未结束任务。本机入口取回用户原话和最新处理状态。没有接续对象时说明缺少目标。

对采用本版 F 持续转化规则的任务，恢复时取回本线当前候选仍有用的来源原件、借法、条件与实际产物，使后续生产者能够继续使用或重研；不只恢复项目数和“已借鉴”摘要，也不以别线较新的用法覆盖本线。按任务原 pin 判断责任，旧任务不被新版本追溯改写。

## 执行与呈现

`EXECUTING` 以同 SHA 读取 entrypoint 与全部 core，按 manifest 核对声明的 execution_bundle、成员和散列。[原语宪法](CONSTITUTION.md) 适用于本 pin 的所有执行。失败按薄路由报告，旧缓存不用于本条必需的获取。WORKBENCH、Chat 导出及增量按实际用途读取。获知本机 `toolchain.json` 只提供工具定位。

本次 `EXECUTING` 的同 SHA 核心验证成功后，即查询 OpenRouter 公共模型目录中的 `anthropic/claude-sonnet-5.5` 与 `google/gemini-4-carbon`。逐条在 commentary 流式显示模型、每百万 token 输入与输出美元价、来源和查询时间。使用 `acquire --stage execution --stream-quotes` 时转播该入口刷出的各条事件；已用 GitHub 连接器验证 pin 时可用 `profile quotes` 或直接只读同一公共端点。查询成功和失败均独立于发送权限、费用预留、钱包、U0 与任务接续。缺价时显示对应模型暂缺当前报价，继续任务。单独查看普通状态或恢复已对接的同一调用不自动再查。

恢复先处理最新用户来源、实际活动、当前角色和待转播点。真实纠正进入 [FOUNDATION](FOUNDATION.md)，暂停或停止立即作用于相应活动。生命周期既不能由旧标志恢复，也不能由普通回复结束。只有实际返回并收口或明确终止才结束。

新任务形成 U0 和正式配置时，按 [PROTOCOL](PROTOCOL.md#主动寻找值得投入的机会) 主动发现能改善交付的请教和原生加深机会。当前单冒号选择按 [独立首发](PROTOCOL.md#单冒号任务的独立首发) 把机会放在实际取舍定案前，原件核对和可逆工作照常推进。恢复时读回真实首发、公开转播、原生再议和已生效的参数，再沿当前决定继续。C1还须恢复[COURT](COURT.md) 的当前案卷、未决指控、返工配置与执行事实；旧判决不覆盖已改变的需求或产品，真实终止保留未完成范围。

取得完整核心即开始按 [LIVE](LIVE.md) 从真实边界发布到 commentary。初次先显示实际 U0；正式决定成立后才发正式 INIT 和实质工作阶段。独立返回、主线处理以及公开流读回都从实际当前状态接续。不存在可信时钟、隔离代理或宿主侧发布能力时，继续可做的工作并按实际能力报告。

新任务C按显式选择优先；省略时Max默认1、其余档0。同任务省略C继承当前值，单改档位不重设。每层真实U0之后执行FOUNDATION短协议自提醒；未发生U0不为提醒新增递归层。
