# 参数、每单位责任与可见过程

参数是投入责任，不是质量分、命令数、字数或角色名额。自然工作整体决定单位重量，在同一任务中保持一致；不能把搜索、打开、阅读、记笔记拆成四次推进。研究后有据保留、推翻昂贵路线或发现错误前提也可以是实质贡献。

## 调用与初始化

初始化分为FOUNDATION前置与正式执行。先保留调用原文、已给参数和实际限制；前置按FOUNDATION独立研究并显示投入。用户对任务说明及关键取舍明确决定后，再补齐本节的正式配置并显示DIGR INIT OK。前置预算/时长单列，不抵扣用户给正式任务的N/T/R/S/D/V。已有确认续做只处理重要变化，不重新要求确认。以下默认深度与单位责任指正式任务；专门委托建设前置阶段的任务仍按自己的调用执行。

只有同 pin STARTUP 分类为 EXECUTING 才建立参数。调用冒号后的任务原文完整保留。支持标签 `N=16` / `N(16)` / `N（16）`，S 内用 n/t/r/b，新增 M 标签；数字计数为非负整数，M 至少1，B/b 为0或1，Codex L 固定3。位置写法只接受无歧义的公共序列 N,T,R,B,S(n,t,r,b),D,V,L，新增 M 用标签，不能把旧位置值误读为 M。全角标点可归一用于理解，原输入仍保留。脚本不代替语义解释。

无参数深执行从 **N12/R4/D3/V3/L3/M1** 补齐，复杂任务自主上调。T/t 按任务形成有依据的软目标，不默认复用上次值；S 按需要外部材料支持的真实问题划分。`target=60min` 为软 T，`min=60min` 为硬 T；秒/分/小时须明确单位。显式裸数字的时间单位不明时询问，不借旧 parser 猜测。`standard` 是用户主动选择的 N2/T0/R1/B0/S(0,0,0,0)/D0/V0/L3/M1、来源AUTO低档；其零下限仍允许有价值的来源/D/V工作，绝非自动降档入口。

source 默认 REQUIRED；auto 由模型按当前问题选择 REQUIRED/WAIVED 并说明依据；off 为 WAIVED 且 S 下限为0，与显式非零来源下限冲突时指出。显式 B1/b1 未给时长时补齐有任务依据的正时长。显式低 L 与本通道冲突，说明而不悄改。关键冲突未解显示 INIT BLOCKED，继续不依赖它的工作。

各 M 都完整补齐 N/T/R/B/S(n,t,r,b)/D/V/L。用户公共显式值适用于每条线；若明确指定某 M 的配置，按其范围执行。各线可独立上调和改变方法，保留理由与实际后果。已建立的 N/R/D/V 承诺只自主上调；用户改目标或明确改参数另按其意图处理。D0/V0 是零下限，仍允许有价值的独立工作。

自主上调以真实未承担的问题为依据：N需要更多实质推进，R需要另一个能改变整体判断的重开，D需要实际竞争介入，V需要可持续的新领域。先找能改变结果的方法，别用增大数字替代它。M扩线须有值得独立发展并收敛的整体路线，说明完整责任和资源后果；显式人数/预算上限仍有效，不为了填槽扩大M。每次生效调整展示新目标及原因；未来计划、侦察和已完成事实分开。

## 单位责任

| 参数 | 每一单位必须实际承担什么 |
| --- | --- |
| **N** | 一项有交付意义的主线问题，经认真研究、比较或制作，走到足以改变理解、路线、证据或成品的更好状态。机械提交、润色、例行测试或记一次日志本身不各算一轮。 |
| **R** | 带着不同关键问题，重新研究已有完整候选及其产生路线，比较真正可能改变整体判断的解释或方案，重新综合并落实改变或给出有内容的保留理由。四章校对不等于整个任务 R4。 |
| **D** | 一次成熟的非局部介入：独立者发现支配前提或高价值机会，形成强替代，实际研究/试作，返回可作取舍的结果；Main 回答中心主张并处理后果。只派制作工单、技术失败或未答原问题不能补成完成。未采纳但充分研究、已被认真处理的介入可以完成。 |
| **V** | 一条有真实语义距离、持续发展的独立领域。它有自己的材料和研究空间，主动形成问题、方法与作品，随领域自身进展和相关候选变化继续研究，向主线带回有内容的发现或成果；多次回传仍为一条 V。来源分工或结尾一句点评不构成持续异质性。 |
| **M** | 一条完整独立主进度：各自真实初始化、动态推进、履行本线 N/R/D/V 与来源责任，形成可检查候选，收敛并参与最终比较。建一个目录、开一个代理或分摊总次数不构成1M。M1也是真正负责生产与综合的主线。 |
| **L** | 执行隔离模式，非计数。Codex 只用 L3：真实独立代理、受控输入、分开的模型历史和工具执行循环。共享磁盘不是 OS 保密；全历史 fork、同模型换角色名或事后背书均不满足。 |

D 起步可以是尚未成旗的自主侦察；完整1D要求成熟行动与 Main 处理，不能反过来用完成条件禁止其探索。V 的分域来自前期探索与议会讨论，不由 Main 预填三个通用角色。具体自主权与交流见 COLLABORATION。

来源责任同样按工作解释：一个 S 工作面是持续研究一个真实问题；1n 是该面一次实质证据/理解推进并影响问题；1r 是重研该面的结论或方法，例如追查冲突、换原始材料或寻找反例并处理后果。网址不各算一面，再打开一次不算重开。代码、原件、论文、官方材料、社区和试作均可作适当来源。

N推进，R重开整体，D竞争性介入，V发展异质领域，M负责完整推进。R/D/V 的后果可以形成 N，但要确有 Main 的研究、取舍或成品改进，不能同一发言贴四个标签。多条 M 共享证据不复制责任计数；各自使用证据完成了什么要分别说明。

## 时间与恢复

**T** 计 MAIN+SOURCE 的实际区间并集，**t** 只计 SOURCE；独占 D/V、META、空闲、排队和等待不计。并行一分钟不会变两分钟。**B/b** 是软硬二值策略：0软目标，1硬下限，无逐轮累加含义。软目标不是到点结束，硬下限不能靠等待或重复检查补足。

每条 M 有自己的活动边界和 T/t。全任务汇总仅合并可比较同域区间；COMMON 共同工作只进全局，不反填各线。多时钟域分别展示，不盲加成全局并集。分别报告参数责任和有证据的时间，不从人数、文字、mtime 或墙钟推算有效工作。

时间读实际工具时钟；显式活动边界说明当前状态和区间是否真实连续。单调时钟身份只证明读数可比较，不能证明期间始终工作。Windows 可用明确识别的存活进程 PID+创建时间作时钟域锚；进程死亡、域改变或未知时保留缺口。恢复丢弃开放尾段，保留已闭合小计，再开新段；不回填此前未记录工作。没有可信边界时写 ?，继续其它责任，不篡改硬目标为软目标。

## 身份与公开显示

初始化所有参数用 **符号（生效值）**，不带斜线；结束用 **符号（目标/实际）**，B/b 单值。中途直接渲染在用户可见 commentary，不以文件、stdout 或结束回放代替；不记录隐藏思维链。

初始化成功后、首项实质执行前输出。以下仅为格式示例，真实时长和配置按本次任务决定：

```text
[DIGR INIT OK] 生效配置：
DIGR（N（12），T（90min），R（4），B（0），
S（n（3），t（40min），r（1），b（0）），D（3），V（3），L（3），M（1））
时间=<工具实采本地时间及偏移>｜墙钟=<实际/?>｜T/t=<分别软硬>
source=<REQUIRED/WAIVED>｜P_run=<版本@完整SHA>｜clock=<实际能力与验证范围>
```

M>1 时先显示共同 M，再逐线显示 `M01：DIGR（N（…）…L（3））` 的完整初始化。新增/上调在生效时展示，未准备好的线保留状态，不以第一条配置复制称全体已初始化。

| 工作身份 | 中途标题（示例） | 身份实质 |
| --- | --- | --- |
| Main推进 | 🟦 **M01·N03｜原页组装路线** | 具体职责或目的；通常由该 Main 研究制作，别演成 N 与 Main 两个人。M1可省 M01。 |
| 整体重开 | 🟪 **M01·R02｜整套读物是否破坏知识连续性** | 真实完整候选、值得重新研究的关键问题。 |
| 独裁介入 | 🟧 **M01·D02｜原页直接组装应替代先全文清洗** | 干预对象、成熟旗帜；侦察期可写正在争夺的问题，尚未证明的主张仍标为主张。 |
| 持续视角 | 🟩 **M01·V02.2｜阅读依赖领域：新候选缺失的定义** | 稳定分域与当下问题；.2 是同线再入，不是第二条 V。 |
| 来源研究 | 🟨 **M01·S1.n02｜实际导出能力** | 工作面及具体推进，重开用 r。 |
| 主进度汇合 | 🟥 **M02｜独立候选收敛** | 哪条完整主进度、当前方案与与其它主进度的实际互动。 |

标题下独立阶段行：**▶ 开始 / ⋯ 进展 / ↻ 再入 / ↩ 返回 / ◆ 主线处理 / ✓ 完成 / ■ 线路关闭 / ⏸ 受阻**。正文说真正的问题、材料、所得和后果。独立返回摘要放引用块，Main 处理回到正文；逐字引文与概括区分。只有实际启动后才称开始，发出不等于已读，收到不等于完成。

每个实质 N/R/n/r 在选题和方法形成后报开始，真实结束报完成；可以同条消息合并不同真实边界，但不得预排或补造。D/V 初次及执行者变化时说明真实代理。D 的返回与 Main 的实质处理分别可辨，V 在相关阶段再入，不要求每次小改全员同步。处理回答中心主张、理由和已落实/待落实/拒绝的后果，不用“收到/已采纳”代替。

长轮次有实质发现沿同身份报进展，遵守宿主沟通时限；无变化不发心跳。必要事实尾行放真实时间、墙钟、阶段或材料范围，免重复整份参数表。调整参数/方法时用 `⚙️ **DIGR｜投入与方法调整**` 说变化、原因与资源后果。时间参数和 L 不编“第几轮”。

## 返回

按必读 RETURN 先交付结果、入口、关键后果、时间—工作标识图（或明确部分记录/文字回退）、依据和实际限制，再紧凑报事实。任务结束应收口生命周期；澄清/等待回复不是已结束交付。

```text
DIGR（N（目标/实际），T（目标时长/实际或?），R（目标/实际），B（0），
S（n（目标/实际），t（目标时长/实际或?），r（目标/实际），b（0）），
D（目标/实际），V（目标/实际），L（3/实际），M（目标/实际））
报告范围=<可核对/自报/部分证据/未知>｜T/t=<软硬及记录范围>｜墙钟=<实采>
P_run=<版本@完整SHA>｜来源工作面=<数量>｜D/V独占时长=<实际/?>
```

M>1 逐线返回完整参数事实，并另报 M 与全局可比区间并集；不能用总数掩盖某线未完成。S 同目标的 n/r 取各面最小值，异构目标逐面列。有效 M/V/D 依实际责任判断，不从注册数、状态声明或脚本自动换算。实际未完成清楚说明，不能为整齐静默减目标。此报告不是 canonical 认证、质量分或跨任务收益证明。
