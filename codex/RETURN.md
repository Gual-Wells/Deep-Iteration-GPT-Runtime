# 返回正文与任务收口

这是 EXECUTING 必读的执行语义。最终报告直接写在用户可见的response正文，固定五个二级标题和顺序：

1. **结果**：交付答案、判断或成品入口。正文独立可读，关键论据可以就在这里，不为分栏拆断论证。研究解释本身可以是成品。
2. **关键变化**：说明形成的认识、决定及实际后果。研究无基线时不虚构改前/改后；提议、已执行与已观察效果分清。
3. **工作过程**：正文Markdown时间／工作表，选择影响结果的研究、制作、异议、处理与落实。写真实区间、近似或未单列，不抄命令流水账，不为每个参数单位补造分钟。
4. **核验与限制**：说明实际核对、依据范围及影响使用的缺口。不把测试数、哈希或代理完成当作品品质证明。
5. **参数**：按PARAMETERS返回目标／实际、T/t及补点缺口、P_run；责任数量由实际工作判断。

段内可自然成文，保留小标题、代码、表格和真实产物链接。短任务每段可以很短，不用空模板、无关检查或重复内容凑段。研究、工程和创作保留各自的论证与表达。

**禁止HTML/iframe/details内嵌页、附件卡、Page、文件截图、整份代码围栏或“请打开文件查看”替代报告正文。** 书、图、网页、代码等任务本来需要的成品可链接或展示；报告保存副本只补充追溯。时间图不再是默认要求，历史timeline工具按明确用途使用，不重新嵌成默认报告。

## 共同访时，收尾统计

所有实际参与者含D/V向同一文件追加Begin/End，以run_id、actor、line、phase、category分组。任务只关联文件位置与分组，不携带运行中timer状态；普通记录不以PID、进程锚、单调钟身份或连续性证书为接收门槛。

**T是WORK+SOURCE区间并集，t是SOURCE区间并集。** 并行重叠只计一次，D/V照计；META、排队、等待和空闲不计，等待前结束活动。FOUNDATION与EXECUTION分开；每M统计本线所有参与者，全局再并集，COMMON只进全局不反填各线。

缺End、重复Begin、坏行和倒退时刻局部保留，其它配对照算。新Begin不替旧段闭合，未闭合尾段不延到现在。收尾有可见依据时追加近似补点：指向原Begin，标approximate/basis，分开有效结束时刻与实际补录时刻；无依据留缺口，不覆盖原记录。按事件身份去重。默认只报一对含已接受补点的T/t、补点数与未解缺口数，工作表说明相关近似与依据，不强制两套总值或精度评分。

T/t表示登记覆盖，允许打断和长上下文扰动，不认证每秒活动或完整历史；缺单调钟身份不使它整体无效。硬下限仍保留原意，不改软、不靠等待补足；记录明显不足的范围如实写未验证。

## 保存正文，真正发回

`return seal/status/body/close`保存并核对选定五段Markdown、本任务事实和产物；body直接输出准备发到response的正文。收口时结束真实活动，处理重要未决事项，seal，读取body并直接发在最终对话，close终结生命周期。封存和收尾的少量管理时间不另开生产计时。

共同文件仅以本run的去重投影绑定返回；其它run追加、相同事件重放不使本返回失效，本任务新事实会使其STALE。缺End可带明示缺口收口，不为访时完整另造保障工程。READY只说明所选保存内容当前，不能证明事实真实、责任达标、正文已发送或用户已看到；没有宿主发送事件就不声称机械保证response。

0.8.1起新会话用session-3和schema-2正文；旧pin及旧会话保持原身份与原工具口径，不静默迁移，历史图文路径不作为新版绕行默认。澄清、等待与中途进展不收口；暂停禁止继续相应活动但保留任务，停止/取消优先，不要求先封存报告。未实际完成本RETURN并收口前，补充、纠正和宿主新轮都沿原任务；普通消息处置更新输入锚点，不能沿旧封存返回越过新要求。0.8.2正常CLOSED须引用现有机制核准的当前receipt，裸关闭或任意草稿不构成结束返回。模型仍须实际发送当前正文，工具不认证语义质量或宿主送达。已结束任务不因普通输入或旧确认复活。

按实际片段区分DIGR、普通轻量、Goal和协议模拟。新前缀仍真实获取，原P_run冻结；其他宿主缺独立代理、文件或时钟时如实说明，不能以同模型角色扮演冒充L3。
