# DIGR Codex 0.5.1 使用说明

普通任务使用简短交付偏好；显式 DIGR 进入高投入的问题研究、方案探索和成品改进。默认起点由用户选择：N12/R4/D3/V3，复杂任务上调。Codex 的 D/V 固定真实独立代理与 L3，不安排低 L 或低 L 兜底。

| 用法 | 行为 |
| --- | --- |
| `DIGR：任务` / `深度迭代：任务` | 高投入深执行；先读完整协议和每单位责任，来源默认 REQUIRED |
| `DIGR(N=16,R=5,D(4),V(4),L(3))：任务` | 显式提高投入；位置或标签有歧义时不能猜，任务正文保留 |
| `DIGR(target=60min)：任务` | 软时间目标，不覆盖 N/R/D/V 高投入偏好，也不代表时间到就结束 |
| `DIGR(min=60min)：任务` | 请求硬时间下限，按真实计时处理；不能靠等待凑足 |
| `DIGR(standard)：任务` | 用户主动选择的低投入档 N2/R1/D0/V0/L3，不能自动替代默认深执行；实际D/V仍须L3 |
| `DIGR/help` | 帮助，不启动任务 |
| `DIGR是什么？` | 候选获取后由仓库分类为普通讨论 |
| `digr：任务` / `Digr：任务` | 不命中精确前缀路由 |

[执行协议](PROTOCOL.md) 与 [参数单位责任](PARAMETERS.md) 均为 EXECUTING 必读；[工作台](WORKBENCH.md) 按需使用。工作台工具帮助聚焦问题、取回材料、准备 D/V 研究输入；不派代理、不打思想分，也不据此声称完成深执行。

普通任务同步采用有价值的讨论/纠正/分工后果留痕；显式深执行增加高投入单位责任。无参数下限只自主上调，方法与资源可自主选择，已有授权不重复申请。R可深入研究后有根据保留方案，不要求制造新缺陷。`record`可选写入现有工作小节；直接编辑笔记照常有效，不要求另建日志系统。

## 实际会看到什么

初始化只显示生效值，每项带参数符号，不带“/实际值”。随后给必要来源、时间软硬、执行pin和计时能力。以下只是**格式示例**：

```text
[DIGR INIT OK] 生效配置：
DIGR（N（12），T（75min），R（4），B（0），
S（n（3），t（30min），r（1），b（0）），D（3），V（3），L（3））
T/t=软目标 | source=REQUIRED | 时间/墙钟/P_run/clock=<实际运行填入>
```

按顺序读就是：主线推进至少12次，软时间目标75分钟，整体重新开题至少4次；来源各面至少3次实质推进、软时间目标30分钟、至少1次重开；至少3项实际介入、3条持续异质线路，D/V使用真实L3。两个0表示时间是软目标。它们是投入责任，不是预先取得的成绩。真实运行不能省去示例中的实际事实字段；时间目标也不会自动沿用这组数。

中途直接渲染色块与粗体身份，阶段另行显示，正文随真实工作而变：

| 你看到的部分 | 应当说清什么 |
| --- | --- |
| 🟦 **N03｜确定原页组装路线** | Main正在推进什么、为什么、怎样研究 |
| 🟪 **R02｜重开整套读物的知识连续性** | 从哪个新问题重研哪个完整候选 |
| 🟧 **D01｜试作原页组装，挑战先全文清洗** | 针对什么前提提出什么强替代，谁实际去做 |
| 🟩 **V02.2｜学习依赖视角** | 同一线路基于什么新材料，继续追什么问题 |
| **↩ 独立返回** 与 **◆ 主线处理** | 独立所得、Main取舍理由及实际改动分别可辨 |

表内是设计示例。标题标身份，下一行以“▶ 开始／↩ 返回／◆ 主线处理／↻ 继续研究／✓ 完成”等标阶段。返回摘要缩进为引用块，Main处理回到正文，必要时间与进度放块末。中途不重复参数表，也不强制每条填一套栏目。V再入不是新增V，一次有贡献也不等于关闭；N/R通常由Main执行，D/V首次说明真实执行者，后续沿用短名。

V始终独立，只由Main转交必要质疑；不会通过互看笔记制造共识。异步或多问时要明确正在回答哪个委托/候选。Main处理中心主张，不以“已收到/已采纳”代替理由和实际改动。阶段动词、旧材料范围和未落实处不能为简短省掉；同时也不要求每条消息重播完整合同或人物名片。

结束采用同次序、每项“符号（目标/实际）”，如N（12/12）、D（3/2）；B/b策略单值，不编造实际量。未知有效时间写?，墙钟不能代替T/t。具体显示并非新的用户调用语法。完整规则位于PARAMETERS的“初始化与轮次输出”和“结束报告”，连贯示例见[改造入口](../docs/CODEX_ADAPTATION.md)。

普通任务仍使用轻量交付偏好，不启动这些参数、角色或计时。进行中的澄清/压缩恢复继续原任务，不重发INIT；新的普通任务不继承DIGR。历史展示、格式示例和转述各标明性质，不能用结尾回放补造现场。

保持 main 的公共参数次序 N,T,R,B,S(n,t,r,b),D(s),V(o),L(e)。显式值优先；source=auto 按问题决定来源，source=off 与非零 S 下限不能同时成立。参数由模型解释，不能混用根目录 Alpha 5 的旧参数解析器。

一个 N/R/D/V 的重量以实质责任为准，不能按工具动作、发言次数或人数凑数。详见 [应用演练](examples/UNIT_RESPONSIBILITY.md)。有真实候选后才有 R，D 需要实际介入并回主线，V 需要持续且非重复的研究。

本版是独立实验 profile，采用 codex/manifest.json 和 codex/VERSION。当前生产 stable 路由不会因分支更新自动切换。安装和设计依据见 [改造说明](../docs/CODEX_ADAPTATION.md)。
