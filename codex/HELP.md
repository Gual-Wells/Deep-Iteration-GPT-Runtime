# DIGR Codex 0.1 使用说明

这是独立实验 profile。根目录仍是 stable Alpha 5；只有明确选用实验路由、真实取得实验分支 pin 并读到 `codex/manifest.json` 才使用本版。把本地候选文件读一遍不等于启用新的生产协议。

| 用法 | 行为 |
| --- | --- |
| 普通用户请求 | 默认轻量交付约束，直接完成任务；不启动 DIGR 时钟/计数/证明。 |
| `DIGR：任务` / `深度迭代：任务` | 自适应深执行。默认要有来源工作，时间是软目标，围绕具体产物持续改进和回查。 |
| `DIGR(standard)：任务` | N2/T0/R1/B0/S(0,0,0,0)/D0/V0/L1；来源按任务决定。 |
| `DIGR(N=3,R=1,target=20min)：任务` | 显式演进/回查下限与软时间目标，完成标准仍是实际结果。 |
| `DIGR(min=20min)：任务` | 请求硬时间下限；只认可真实计时，不靠等待补足。无法证明时必须说明。 |
| `DIGR(source=off)：任务` | 明确不做来源工作，不能同时要求非零 S 下限。 |
| `DIGR/help` | 帮助，不启动任务。 |
| `DIGR是什么？` | 候选获取后由仓库分类为普通讨论，原文返回普通处理。 |
| `digr：任务` / `Digr：任务` | 不命中 DIGR 候选路由。 |

参数含义与冲突处理见 [完整协议](PROTOCOL.md)。辅助 CLI 只检查分发文件与宿主边界，不替模型执行参数或思考。

运行中的补充/澄清延续当前任务；明确改目标需要对齐修订。新普通轮次不粘连 DIGR。能力和证明分开：没有最终输出拦截器仍可原生执行；不能因此声称 CANONICAL，未知时间必须写 `?`。

安装和离线试用见 [Codex 适配说明](../docs/CODEX_ADAPTATION.md)。不默认调用付费 API、派代理、创建 Goal 或改变全局设置。
