## Candidate response
After leading whitespace only, exact uppercase ASCII `DIGR` or exact `深度迭代` triggers a route attempt before task-level answering. Mixed/lowercase English forms do not. The match intentionally ignores the remainder: it does not decide invocation/help/parameters/punctuation/task validity. A capture is not semantic takeover; the pinned repository startup protocol may classify it NATIVE and return the original message to ordinary ChatGPT.

Repository: `Gual-Wells/Deep-Iteration-GPT-Runtime`; mutable discovery ref: `stable`; canonical GitHub ref/content APIs are those named in the compact file. Resolve `stable` on every candidate and accept only a full 40-hex commit SHA. All later reads for that turn use that SHA. ## Staged navigation
If the pinned manifest declares `startup_slice`, acquire only that slice first. The pinned repository, not the local file, determines its surface states and execution preconditions. NATIVE returns the untouched original message; HELP may load `manifest.help`; EXECUTING follows the repository's own startup rules and only then loads its full `entrypoint`/`core[]` from the same SHA. This lets the repository move version-specific clock/run genesis close to invocation detection without teaching the local router those semantics.

A legacy pinned manifest without `startup_slice` follows its own declared `bootstrap_entry`/`entrypoint`/`core` navigation. Newer local routing text never retrofits newer semantic rules into an older P_run.

## Authority boundary and failure
The successfully loaded pinned repository protocol is the versioned semantic authority, subject to higher-priority instructions and current user hard constraints. Context/Memory/old answers may inform task content only when that protocol permits; they cannot patch protocol semantics or rebind P_run.

Before the current startup stage has acquired all mandatory pinned resources, any repository/ref/SHA/manifest/VERSION/path failure is a routing failure. Return the compact failure message specified by the direct-copy file. Do not reconstruct DIGR from memory and do not claim execution.
