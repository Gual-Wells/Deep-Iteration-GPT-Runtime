# English-Spoken-Preprint

Create a scene worth hearing, then make it easy to carry to a phone. ESP is a production workflow, not a DIGR execution protocol. Respect an actual acquired DIGR profile when explicitly invoked; never count fictional M/D/world roles as formal protocol responsibilities.

The purpose is understanding and later reusing language in personally relevant difficult situations. A frictionless expert exchange or wrong-domain interview can be unsuitable even if accurate. Distinguish situational difficulty from incomprehensible learning input. Do not impose failure quotas or a cognitive knowledge allowlist. General reasoning remains available; invented personal experience, observed tests and outcomes do not.

Current scope: the user listens. Do not add role takeover, user insertion, mobile handoff, tests for the listener or a new reader. Human-involved Codex training is a separate design exploration, not an ESP dependency. Constructing ESP does not activate English rehearsal in this chat.

## Run actual characters

Each character gets separate native outward M and inner D contexts, initialized from that person's own persona/background and current `packet`. Do not fork full controller history, shared backstage files, other minds or a complete scripted future into them. Shared disk is not OS secrecy; respect controlled reads rather than claiming stronger isolation.

D authors fictional inner speech, not hidden model reasoning. Fear, pride, selfishness, warmth, misconception and distraction may coexist. M's real words can contradict D; M can privately ask, reject or reinterpret, and D must actually receive the new input before responding. Avoid a fixed D→M→D approval pipeline for every utterance. Silence or an unresolved private exchange is allowed.

Submit only the originating context's actual words/actions with source and executor attribution. Give the next person actual preceding public contributions and their own new perceptions. Allow refusal, wasted efforts, mistakes and changes of plan. Do not write the whole dialogue yourself and relabel its lines as native actors. Sequential host scheduling is not simultaneous residence or measured human latency.

When the observed situation changes, reconsider relevant world activity; do not call all earlier proposals fulfilled. Permit ordinary unopposed self-actions; confirm important consequences, blocking conditions or effects on others with sourced world decisions. Distinguish completed action, promise and attempt. Accepted events are the record; the small state table indexes reusable constraints, not every physical detail. A modest unspecified prop can be co-created explicitly. Choose a natural ending with consequences still intact; the original seed's future is discardable.

## Publish and check

Use `preprint publish` to create a new edition. `phone/PHONE.txt` is the primary whole-scene listening input; `LISTEN.md` is the public log. The public scene and cast introduction need the same factual care as dialogue: they must not certify a character's disputed CV claim or reveal private knowledge. A historical correction must be labelled as editorial and must not rewrite native returns or pretend actors received a corrected past. Creator material stays outside `phone/`; do not copy raw spec/personas/world/inner events into it.

The phone performs the preprint's roles in natural sequence for listening. It is a single host interpreting a source produced by independent native contexts. It must not require the listener to answer or stand in for somebody. Different voices and timing need verification on the real device; text probes are only text probes.

Read the actual output, compare representative dialogue to the original native returns, check private canaries are absent, and run `verify` against the current source. Source identity and clean exports do not prove dramatic quality, listening improvement or successful phone Voice playback.

Annotate language after the real dialogue exists. Bind exact surface spans, meanings, communicative functions and register to public source events; verify frequency claims with actual corpus evidence or say unverified. Do not infer mastery from fictional actor success or a finished book. Deliver one current entry, the phone package, optional creator edition, sources and real limits.

For current production read `spoken-preprint/LEARNING.md` and `CONTEXT.md` under the tool root. Select complete continuous public exchanges as cases: Chinese situation/intent, exact language meanings and conditions, the actual next response, and distinctly authored short variants. Cross-book exact-use, handling-function and contrastive-use are different relations; only actual matching surfaces can be lexical recurrence. Search explicit roots only.

When the user describes a situation, interpret its communicative need yourself. `preprint find` is literal substring retrieval, not natural-language semantic search. Keep the original request, choose a few short Chinese/English terms, read the full returned exchanges and conditions, and explain fit and limits. A zero-result sentence is not evidence that the pool lacks useful material; shorten/rephrase or read the explicit case inventory. It is optional support, not a compulsory course before enjoying the scene. Keep meaningful replies, objects and outcomes around useful language; isolated reusable spans do not replace the encounter. Characters do not become teachers; the listener need not respond. Finalize any cases/lesson before a current substantive review. Its useful flag is an operator judgement, not semantic certification or proof of learning.

Personal Context is an optional provider of selected current book/role capsules, not a mandatory whole-person database. Preserve claims/resources/unknowns and source scope; do not infer incapacity or mastery. Use owned material reads, frozen history, bounded world territories and finite feedback when they solve a concrete scene problem.
