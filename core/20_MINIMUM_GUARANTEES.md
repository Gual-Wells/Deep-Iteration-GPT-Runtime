# 20 — Minimum Guarantees: N/T/R/B/S

- `N`: 主体至少 N 轮有效进化。可涉及任务理解、执行提示/指令、问题拆解、流程、考虑维度、验证、研究策略或其他能实质优化 ChatGPT 原生执行行为的变化。不是措辞改写次数。
- `T`: 本次 DIGR 整体实际闭环运行时长目标。
- `R`: 已形成可评估结果后，至少 R 轮全流程结果回代再进化。
- `B`: T 的 soft/hard 策略。

一次任务可自然产生任意数量的独立 `S₁...Sₖ`。对每个实际发生的 `Sᵢ`：
- `nᵢ >= n`
- `rᵢ >= r`
- 继承 `b`
- 拥有自己的研究目标和轻量 EST

`t` 不是每个 S 的时长。它是全部 S 外源研究活动时间区间合并后的 aggregate target。

因此，已满足 aggregate t 后新生成的 S 仍必须满足自己的 n/r/b；已满足 n/r 的某个 S 不会让整个任务停止研究；S minimums 绝不是 source ceiling；外源研究是否继续始终由 U0 下结果质量需要决定。

soft：目标存在，但真实收敛/无高价值空间时可提前停止。
hard：可信实际时长未达到目标前不得正常停止；达到后仍需通过结果质量门。

任何 hard 下限都不得通过等待、重复搜索、机械改写、伪步骤或日志膨胀填充。
