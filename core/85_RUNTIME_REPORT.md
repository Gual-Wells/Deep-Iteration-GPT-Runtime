# 85 — Runtime Report

最终结果之后输出 `【DIGR 记录】`。这不是隐藏思维链转录，也不是旧式执行证据证明，而是可公开的运行元数据。

最少字段：

- **参数**：requested N/T（或 auto）、解析后的复杂度等级；注明 T 是参考复杂度而非实际墙钟耗时。
- **提示词迭代**：最低要求、实际有效循环次数、是否满足下限。
- **最终迭代提示词 P***：公开用户级执行提示词。
- **进化度量**：规定指标的 `initial → final (delta)`，0–5 整数。
- **回检**：正式重做次数；若 >0，列高层触发原因。
- **实际流程链**：只列真实发生的高层步骤，不输出思维链。
- **查询/引用来源**：只列实际查询/读取/调用并对结果有用的来源及用途；无则写“无外部查询”。

禁止：虚构迭代次数、虚构时间、虚构重做、虚构测试/来源、运行实例 ID、调用栈、逐步隐藏推理。
