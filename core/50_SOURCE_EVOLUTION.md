# Source Evolution

Adaptive Berta2 defaults to `source=required`: use external evidence when it can materially ground the task. External source includes web, official docs, repositories/code, user files, datasets, papers, community material and tool/test outputs.

Explicit `source=auto` allows the model to choose REQUIRED or a concrete task-grounded WAIVED disposition. Valid waiver examples include a closed transformation where external input is forbidden or genuinely irrelevant. “The model already knows” is insufficient. `source=off` is an explicit user policy and forces zero S minima.

Each counted S instance has a real workspace, active SOURCE binding and semantic event. n/r are per qualified source; t is SOURCE clock union. Source choice, query design, conflict resolution and synthesis are native decisions.
