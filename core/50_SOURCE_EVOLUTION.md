# 50 — Source Evolution (S)

S 是作用域限定在外源资料研究目标上的、与主体同构的进化闭环。

每个 `Sᵢ`：
1. 有明确但可进化理解的研究目标 `Qᵢ`；
2. 维护自己的轻量 EST；
3. 至少完成 n 轮有效进化；
4. 进行真实的查询、搜罗、阅读、源码/数据/文档检查、交叉论证等；
5. 形成当前研究结论；
6. 至少 r 次将研究结果回代 `Qᵢ`，全流程寻找新的突破点并实际再进化；
7. 把有效发现回注主体结果与 Main EST。

`n/r` 与主体 `N/R` 使用同等质量标准，而不是“多搜几个关键词/再读一次结果”。

同一主任务可在任意时点产生新的独立 S；它们不是预先固定数量。相同研究问题的不同证据路径通常仍属于一个 S 内部自然进化；新的独立研究问题可形成新的 S。

`t` 是所有 S 的 aggregate source-time 目标，由全部 source-active 时间区间并集计算，而不是把并行调用耗时相加。Source-active 可包含真正以外源研究为主体的查询、抓取、阅读、源码检查、资料解析、交叉验证、证据驱动分析与论证。不可用纯等待或故意拖慢工具填充。

`t` 达标绝不关闭 source work。后续结果质量仍需资料时继续研究。

新增来源/工具/资料工作的价值取决于它是否可能改变结论、降低关键不确定性、发现失败模式或提高可执行性，而不是来源数量本身。
