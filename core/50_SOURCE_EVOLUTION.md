# Source Evolution

SourceDisposition is REQUIRED unless explicitly waived by U0/host reality. A real S actual requires a SourceWorkspace, SOURCE timing/activity binding and semantic SOURCE evolution/re-entry evidence.

External source work should be timed where it actually happens. Before leaving the runtime to a web/GitHub/connector/tool call that performs substantive source work, enter SOURCE with the relevant active_source_ids and open a work lease. On verified resume, SOURCE is restored and the bridged interval contributes to both T and t.

If the lease is missed, the cross-host interval is retained as an unattributed coverage gap and receives **no t/T credit**. It does not poison the whole run: hard t remains a lower-bound proof over counted hard-verifiable SOURCE intervals, so additional correctly attributed work can still satisfy the target.

SourceDisposition=WAIVED makes source instance/n/r/t gates non-applicable; the fixed b default does not resurrect a waived source obligation.

Parallel active sources share the same SOURCE wall interval; t is the union of SOURCE foreground time and is never multiplied by the number of source workspaces. n/r remain per-actual-source minima backed by semantic receipts.
