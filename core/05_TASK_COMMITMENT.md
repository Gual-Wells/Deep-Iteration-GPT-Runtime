# Task Commitment

DIGR is a high-investment execution contract whose primary object is the best faithful result under immutable user intent `U0`. Its exoskeleton constrains reliability and stopping, not the model's intelligence.

The Alpha 9 lifecycle is:

`P_run → Surface → exact runtime/package attestation → verified full-protocol receipt → Clock Genesis → Parameter Resolution → U0 → Effective Contract → MAIN/Strategy Genesis → N/S/D/R as useful → Completion → finalization admission → FINISH → Result + proof`.

The first package/protocol stages are preflight. No live run exists until Genesis, and a born run has no mandatory repository or protocol-bundle transport dependency remaining.

Only authority, U0, user hard constraints and Effective Contract commitments are frozen. Count/D fields are minima; T/t are B/b-governed timing targets. Strategy, decomposition, source plan, validation plan, assumptions, candidate solution and D gambits remain revisable throughout execution.

B/b default to soft 0. Explicit B=1/b=1 remains a strict verified lower-bound commitment.
