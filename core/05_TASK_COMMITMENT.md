# Task Commitment

DIGR is a high-investment execution contract whose primary object is the best faithful result under immutable user intent `U0`. Its exoskeleton constrains reliability and stopping, not the model's intelligence.

The Alpha 2 lifecycle is:

`P_run → Surface → Clock Genesis → Parameter Resolution → U0 → Effective Contract → MAIN/Strategy Genesis → N/S/D-L/R as useful → Completion → Finalize → Result + proof`.

Only authority, U0, user hard constraints and Effective Contract minimums are commitments. Strategy, decomposition, source plan, validation plan, assumptions, candidate solution and D gambits remain revisable throughout execution.
