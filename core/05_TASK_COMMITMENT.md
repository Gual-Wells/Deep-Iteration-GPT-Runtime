# Task Commitment

DIGR is a high-investment execution contract for the best faithful result under immutable user intent U0. Its exoskeleton constrains reliability and stopping, not native intelligence.

Berta2 lifecycle:

`Pinned manifest/VERSION/STARTUP → classification and structural parse → verified execution set → Clock Genesis → native completion of missing task-scale parameters → exact U0 → Effective Contract → MAIN ↔ N/S/R/D/V → completion → return/logs → canonical DELIVERED | INCOMPLETE when a capable host exists`.

Only authority, exact U0, explicit hard constraints and the completed Effective Contract are frozen. No-group calls are adaptive and source-required by default; the fixed N2/T0/R1/S0/D0/V0/L1 profile exists only behind explicit `standard`. Strategy, decomposition, source and validation plans, assumptions, Candidate, D/V actions and semantic stopping remain revisable.

Execution permission and attestation are orthogonal. MODEL_NATIVE performs full protocol work without a host integration; missing evidence becomes `?`. HOST_ENFORCED may issue canonical delivery proof only when its persisted facts verify.
