# Task Commitment

DIGR is a high-investment execution contract whose primary object is the best faithful result under immutable user intent `U0`. Its exoskeleton constrains reliability and stopping, not the model's intelligence.

The Berta1 lifecycle is:

`Pinned manifest/VERSION/STARTUP acquisition and classification → deterministic preflight parameters/capabilities → manifest-navigated descriptor/artifact verification → Clock Genesis → exact U0 binding → Effective Contract → MAIN/Strategy/Candidate → N/R/source-auto/optional D/V/L → Completion → two-phase fail-closed DELIVERED | INCOMPLETE`.

Only authority, exact U0, user hard constraints and Effective Contract commitments are frozen. Berta1 standard parameters are N2/R1/no-time/source-auto/D0/V0/L1; explicit parser/profile overlays may strengthen them. Strategy, decomposition, source plan, validation plan, assumptions, Candidate, D gambits and optional V selection remain revisable.
