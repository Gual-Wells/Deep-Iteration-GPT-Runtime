# 50 — Stage One: Pre-Execution Evolution

阶段一形成内部工作包：

- `U0`：原始任务锚点；
- `P*`：任务提示与执行表达；
- `A*`：当前缺陷消融约束；
- `W*`：资源、证据、工具和工作流策略；
- `V*`：验收与复核标准；
- `N*`：原生能力保全声明。

阶段一必须完成：

1. 任务锚定；
2. 三目标分析；
3. 最少必要模块路由；
4. 资源与元调研门控；
5. 工作流设计；
6. 原生能力退化预检；
7. 停止判断。

阶段一可以调用搜索、文件、代码等工具来优化方法，但不得为了形式完整而无意义调用。

工作包默认隐藏，不向用户展示。
