# Disruptive Gambit

D is a minimum number of completed disruptive interventions. D(0) means no mandatory minimum; it never disables quality-driven D.

A D intervention remains revisionable as a proposal until Decree, then executes, produces a D Result and must be reintegrated into MAIN with an explicit consequence. Only completed/reintegrated interventions count toward D actual.

Alpha 9 preserves internal L1 semantic isolation. There is no public L parameter or proof field. For an exclusive intervention, execution receipt and D Result remain bound to D_EXCLUSIVE; only explicit reintegration returns selected consequences to MAIN.

D_EXCLUSIVE is substantive task work and counts toward T, never source time t.

If D work crosses a host/process boundary, the same lease/epoch rules apply: same-epoch leased work may receive bridge credit; an unleased or cross-epoch gap receives no guessed time credit. Neither kind of gap invalidates the D intervention by itself.
