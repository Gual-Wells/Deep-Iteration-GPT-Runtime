# D — Disruptive Gambit Intervention

D is a non-local intervention, not a second planner. Each intervention binds isolation, revisioned proposal, Decree, execution evidence, result and MAIN reintegration. `D(s)` is only the completed/reintegrated minimum; `D(0)` never disables optional D.

Internally D selects among three opaque semantic mechanisms: D+ pushes a promising value axis beyond the current local optimum; D− removes overwork, decoration, overfitting and artificial trace; Dx (D⊥) changes the coordinate system, domain or governing premise. These are native heuristics, not public call parameters and not fixed templates. The public call remains D.

Canonical execution uses `D_EXCLUSIVE`, belongs to exactly one intervention ID, and receives positive D time. Aborted and unsuccessful attempts remain audited and timed but do not satisfy D(s). A completed D requires evidence and MAIN reintegration; rejecting all D output is valid after independent evaluation.
