# 35 — Prompt Iteration Loop

## 1. 初版
从 U0 形成 `P0`。P0 只做必要结构化，不擅自改变 U0。

## 2. 循环
每轮执行：

`候选 Pk → U0 对照 → 最大残余缺陷 → 修订/保留 → P(k+1)`

优先轮换检查：
1. 意图、事实、目标保真；
2. 硬约束、软偏好、交付、验收；
3. 资源选择、工具链与验证设计；
4. 反例、失败模式与 GPT 缺陷；
5. 删除冗余、提高信息密度。

## 3. 计数
`actual_prompt_iterations` 只统计真实完成的有效循环。N 是下限，不是必须停止点；超过 N 后，只有剩余问题可能实质改变结果时才继续。

## 4. 最终提示词 P*
P* 是可公开展示的**用户级任务执行提示词**。它可以概括 U0、约束、资源策略、交付与验收，但不得包含隐藏思维链、系统/开发者秘密、内部安全机制或逐轮私有推理。

## 5. 防形式主义
不得故意把 P0 写差以制造评分进步，不得为凑 N 做表面改写，不得把每轮完整内部分析输出给用户。
