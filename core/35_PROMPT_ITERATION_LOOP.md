# 35 — Prompt Iteration Loop

从 U0 形成 P0，只做必要结构化。

每轮：`候选 Pk → U0 对照 → 当前最大残余缺陷 → 修订/保留 → P(k+1)`。

优先轮换检查：意图/事实/目标；硬约束与交付验收；资源与 T 落实设计；反例与失败模式；冗余与信息密度。

`actual_prompt_iterations` 只统计真实完成的有效循环。达到 N 后，仅在仍可能实质改善结果时继续。允许公开每轮的高层焦点标签（如“约束完整性”“资源/验证设计”）以增强可观测性，但不得输出隐藏思维链。

P* 是可公开用户级执行提示词，不得包含系统/开发者秘密或内部安全机制。
