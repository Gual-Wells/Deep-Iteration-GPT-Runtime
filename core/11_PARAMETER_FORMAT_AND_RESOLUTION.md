# Parameter Format and Resolution

Public parameter order is:

`N < T < R < B < S < D`

Inside S:

`n < t < r < b`

L is not a public parameter. Any invocation that attempts to provide L/L()/L= or an equivalent L field is INVALID. D isolation uses internal fixed L1; L is neither semantically completed nor returned in canonical proof.

B and b default deterministically to **0 (soft)**. Missing N/T/R/n/t/r/s are semantically completed by native intelligence after the Alpha 9 pre-Genesis execution package/protocol is ready and Clock Genesis has created the live run.

Bare numerics never acquire duration semantics. Mixed positional/labeled syntax must resolve to one legal mapping or fail AMBIGUOUS/INVALID.

S and D markers remain legal anchors. S() leaves n/t/r for semantic completion while b keeps its deterministic soft default. D() leaves s for semantic completion. D(0) means zero completed-D minimum, not “disable D”.

Only explicit B=1 or b=1 creates the corresponding hard verified lower-bound timing commitment.
