# 30 — Evolution State Tree (EST)

EST 是**进化状态记忆**，不是搜索算法。

主体自然维护 Main EST；每个 `Sᵢ` 自然维护自己的 S-EST。其用途是给 ChatGPT 提供清晰的“已经进化到哪里”的工作参考，从而避免长时任务中不断回到前面重新理解、重新推导、重复达到已有进度。

EST 可自然表示：
- 当前主要进化方向；
- 各方向已经达到的最新状态；
- 已确认的关键成果；
- 尚未解决的问题/不确定性；
- 当前仍值得继续的叶或分支；
- 与父状态相比的关键新变化。

EST 不规定 BFS/DFS/MCTS、评分、剪枝、frontier queue，也不规定何时必须开分支、深挖或回溯。下一步怎么走完全由 ChatGPT 原生判断。树只负责留下进化状态参考。

只维护足以继续工作的高层状态。不要保存完整隐藏推理、逐步思维链、冗长日志或无助于继续任务的历史。完成/暂时不活跃的 S 或分支可以压缩成短状态摘要；新证据使其重新重要时再自然展开。

默认从当前有效叶/状态继续，而不是每轮从 U0 重新推理。只有当新证据、R/r 的挑战或 ChatGPT 判断确有必要时，才重新审视更早状态。
