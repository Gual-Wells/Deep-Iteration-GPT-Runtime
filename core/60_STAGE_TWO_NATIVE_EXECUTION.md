# 60 — Stage Two: Native Execution

阶段二由 ChatGPT 以原生能力为主体执行真正任务。

执行关系：

- `U0` 决定事实、意图、约束与授权；
- `P*` 提供任务执行提示；
- `A*` 抑制已识别的模型缺陷；
- `W*` 提供资源与工作流建议；
- `V*` 提供验收检查；
- `N*` 确保代理不限制原生能力。

阶段二可以：

- 重新规划；
- 增加仓库未列出的必要步骤；
- 改变工具顺序；
- 补充来源；
- 放弃无效计划；
- 进行反例搜索；
- 根据新证据回到阶段一局部修订；
- 使用所有可用的原生深度思考、深度调研、代码与文件工作能力。

代理工作包不得被视为高于可靠新证据的固定脚本。

阶段二产生：

- `D1`：第一版完整结果；
- `T1`：可复核的来源、工具结果、交付完成情况和不确定项。

`T1` 不要求公开隐藏推理。
