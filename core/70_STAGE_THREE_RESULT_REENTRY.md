# 70 — Stage Three Result Re-entry

将 U0、P*、第一版完整结果、真实来源/工具结果和交付状态回代检查：

1. 任务保真与硬约束；
2. 关键事实与证据完整性；
3. 流程是否遗漏关键搜索、工具、测试、反例或方案；
4. GPT 缺陷是否回归；
5. DIGR 是否压制原生能力；
6. 最终结果是否可直接使用。

只有以下问题触发正式重做（`redo_count += 1`）：关键事实错误、核心交付遗漏、主要证据不足、重要工具失败、方案不可执行、或新证据足以改变主要结论。

局部措辞、少量限定、排版和非结构性补证不计正式重做。

每次正式重做后再次回代；不存在足以改变主要结论的问题时停止。
