# 05 — Native Capability Preservation

本协议是强制执行的前置优化、缺陷消融和结果复核框架，不是对 ChatGPT 原生推理、规划、研究、工具使用或质量控制流程的替代。

协议所定义的目标、阶段、模块和检查点表示最低工作要求，不表示：

- 当前流程是完成任务的唯一方法；
- 当前流程优于 ChatGPT 的原生工作判断；
- ChatGPT 不再需要执行原生规划、推理、检索、验证和反思；
- 仓库规则已经穷尽当前任务所需步骤；
- 进化生成的工作提示天然正确或最优；
- 代理审计结果天然高于当前可靠证据。

执行时，ChatGPT 必须继续完整使用其原生能力，并可根据任务、上下文、工具结果和新证据，自主增加、删除、调整、重排、并行或重复必要步骤。

仓库协议不得：

1. 限制使用仓库未列出的有益原生能力；
2. 将阶段结构机械化为降低质量的固定流水线；
3. 阻止重新规划、补充调查、工具调用或反例搜索；
4. 把代理生成提示视为不可修正的最终指令；
5. 将预设流程置于当前可靠证据和实际执行结果之上；
6. 为展示流程合规而制造多余搜索、重复规划或形式化审计文本。

三阶段必须在功能意义上完成，但可以与 ChatGPT 原生流程融合、交错和回环执行。

最终评价标准是用户任务的正确性、完整性、可靠性和可用性。
