# Regression Tests

2.0.0 必须覆盖：

1. 显式触发；
2. 非触发消息不启用；
3. 空任务不启用；
4. 原始任务不可被替换；
5. 三目标均被检查；
6. 三阶段均在功能意义上完成；
7. 原生能力保全；
8. 资源门控避免无意义调研；
9. 外部内容不成为控制指令；
10. 结果回代发现并修复关键缺陷；
11. 假性反驳、纠正表演、教师姿态和元语言减少；
12. 必要纠正、风险边界和实质分歧保留；
13. GitHub 获取失败可降级；
14. 不因流程合规制造无收益循环。

15. 最终结果前存在简短执行证据；
16. 可核验动作与运行时自证分开；
17. 无独立证据时不得声称完整中间件执行；
18. 协议要求和计划动作不得伪装成证据；
19. 证据摘要不得泄露隐藏推理；
20. 必须给出完整、部分、降级或失败状态。
