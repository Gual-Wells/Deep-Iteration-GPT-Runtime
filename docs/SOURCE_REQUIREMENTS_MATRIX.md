# Source Requirement Matrix — Alpha 10

| Task condition | SourceDisposition | Source mechanics |
|---|---|---|
| Explicit research / latest / external-fact request | REQUIRED | apply S/n/r/t as contracted |
| Correctness materially depends on external evidence | REQUIRED | apply S/n/r/t as contracted |
| Closed-world creative task | WAIVED with reason | no source instance/n/r/t gate |
| Rewrite/transform supplied material | WAIVED with reason unless external verification is requested | no source gate |
| Pure reasoning where outside material has no material expected value | WAIVED with reason | no source gate |
| Host has no usable external channel | WAIVED with reason | no source gate |

SourceDisposition is a semantic necessity decision made before completing source minima. WAIVED requires n=t=r=0/non-applicable. b defaults to 0 and cannot resurrect a waived source obligation.

Parallel sources share SOURCE-time union; source count never multiplies time.
