# Local Personalization Guide

The local file is deliberately thin and version-neutral. It matches only after leading whitespace: exact-uppercase `DIGR` or exact `深度迭代`. It pins `stable`, validates pinned manifest/VERSION, loads a manifest-declared startup slice if present, then lets that pinned repository classify/initialize the turn.

Broad capture is not takeover: NATIVE returns the original message to ordinary ChatGPT. Legacy pinned manifests without staged startup follow their own declared navigation. Local text must never copy N/T/R/S/D/L/time/proof semantics.
