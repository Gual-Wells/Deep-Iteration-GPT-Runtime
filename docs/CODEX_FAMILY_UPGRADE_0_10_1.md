# 0.10.1 的全族贡献与适用范围

共同改进入核心 `codex/CHARACTER.md`，由实际读取同 pin 核心的 DIGR、DIGRC、DIGRP 使用。它要求从用户当前目的和材料找出缺失关系，改变实际解释或作品，再接回整体；纠正进入受影响的当前版本，历史案例沿真实上下文解释。它不要求固定小课、数值例、互动件、统一口吻或新的评分流程。

| 入口或增量 | 实际落点 | 保留的职责与范围 |
|---|---|---|
| 原生 DIGR | CHARACTER 共同核心 | 完整 Main、原生 N/R/D/V/L/M；不自动启用 Consult |
| DIGRC | 共同核心、CONSULT 与调用系统文字 | 同等实际条件下 Consult 主观指导优先；Main 完整思考与事实责任 |
| DIGRP | 共同核心、paper/PROTOCOL 与 paper 技能 | 当前连接接回原式与整篇，完整论文职责和标准页 PDF；翻译不自动变解构 |
| Paper Knowledge | knowledge 技能的教学与接续段 | 保留当前问题、局部反馈与实际分支；不另造课程或全局掌握判断 |
| Personal Context | personal-context 技能的来源段 | 历史上传引用、现有正文、产物和实际使用分开；不虚构个人能力 |
| English-Spoken-Preprint | spoken-preprint 技能的反馈段 | 修到当前作品，保留真实交换；不把纸面成功当听力效果 |
| Voice Companion | voice-companion 技能的求助段 | 找到当前没接通的关系，给可用帮助并继续场景；不强制新课程 |

技术方案、代码推理和工程知识若是用户需要理解的对象，就属于内容。Codex 承担工具操作、例行实现、组装与验证；Consult 可以发展技术内容和用户明确要求的实施指南，不承担运行管理。判断看实际用途和后果，而非文件类型或是否提到代码。

角色特有权限不外溢：独立启用个人材料、ESP 或 Voice 不创建 DIGR、Consult 或新的费用授权。已有模式识别、原生隔离、发送选择和真实停止规则保持。独立附属的数据格式与场景发行身份未变；这里修订其随核心发行的技能指导。

代码按实际核心 pin 选择论文契约：0.9.x 使用 paper 0.3，0.10.0 使用 paper 0.4.0，0.10.1 起使用 paper 0.4.1。父任务的原生调用身份保留，论文 Consult 只在真实选择且版本匹配的增量作用域生效。旧任务不热迁移，未知/超前作用域不因伪造两个相同字段就生效。

这是当前 Codex 实验通道的全族升级。根 stable 入口保持独立；个人归档、来源原稿和反馈不进入公共分发。测试与独立前向试用分别支持工具兼容和有界行为观察，不能据此宣布模型普遍更优或真实学习收益。
