# DIGR 5.0.0-Berta2 Design

## Repair objective

Berta2 retains Berta1's V, four-clock, typed-anywhere, exact-U0, audit and two-phase-delivery work while repairing the Berta1 P0/P1 regressions found against Alpha4. It is a candidate, not a stable release.

## Responsibility boundary

Deterministic mechanisms own routing, immutable pinning, unique syntax mapping, clock facts, workspace integrity, receipts, audit and delivery binding. Native intelligence owns task-scale completion of missing values, strategy, candidate formation, source/D/V direction and quality stopping.

No-parameter calls are adaptive and source-required. Fixed N2/T0/R1/S0/D0/V0/L1 is only explicit `standard`. Bare durations remain soft; only `min=` is hard. B/b may request task-aware positive time completion.

## Execution and proof

Execution mode and attestation level are orthogonal. MODEL_NATIVE executes the complete pinned protocol even when a client lacks a native HostAdapter. The report exposes unknown actuals as `?` and cannot claim canonical receipts. HOST_ENFORCED uses the reference runtime; only verified evidence grants CANONICAL.

This separation explains client differences without turning them into execution denial. Identical personalization can still encounter different tool runtimes, background suspension, clocks and final-output interception, but the intellectual protocol remains active.

## Reliability closures

- current Candidate delivery binds only its own primary content-addressed payload;
- Berta2 delivery schema v2 binds semantic/audit state and canonical host evidence;
- DELIVERED/INCOMPLETE/ABORTED receive a terminal mutation seal;
- post-terminal V or coordinated state mutation is rejected;
- V is model-native semantic state and not blocked by `viewpoint_max`;
- session-only monotonic time is accepted for a single uninterrupted execution;
- source/time/profile policies compose with V typed syntax.

Canonical D remains one-owner D_EXCLUSIVE in this release. Background D needs a separate concurrent D ledger before it can return without contaminating T and is explicitly deferred.

## Return surface

Every execution returns the task result, targets/actuals including `T目标/T真实（+D真实时间，+V真实时间）`, attestation level, TOTAL and N/T/R/B/S/D/V/L behavior logs. Host-backed logs are content-addressed NDJSON; model-native logs are clearly self-reported/noncanonical. Neither exposes chain-of-thought.
