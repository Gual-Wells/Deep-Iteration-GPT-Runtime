# Routing Transport Contract v2

Candidate match: lstrip then exact uppercase `DIGR` or exact `深度迭代`; remainder unvalidated. Resolve `stable` anew, accept only a commit SHA, and bind pinned manifest/VERSION bytes. All subsequent reads use that SHA.

Alpha 2 manifests declare `startup_slice`; acquire it before repository surface classification. Only after pinned startup says EXECUTING does repository-defined run genesis occur; full entry/core loading follows from the same SHA. NATIVE/HELP avoid unnecessary full protocol loading.

Routing failure before required pinned startup resources are acquired is not DIGR execution and must not be reconstructed from memory/context.
