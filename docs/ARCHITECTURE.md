# DIGR 5.0.0-Berta2 Architecture

Berta2 separates six planes:

1. Local router: broad exact-prefix candidate capture only.
2. Transport/navigation: live stable HEAD → immutable SHA → pinned manifest/VERSION → startup slice.
3. Structural preflight: classification, unique syntax mapping and execution-set integrity.
4. Native intelligence: task-scale completion, Strategy, meaningful Candidate, N/R/source/D/V and semantic stopping.
5. Host evidence: optional clock/workspace/capability receipts with MODEL_NATIVE or HOST_ENFORCED mode and NONE/PARTIAL/CANONICAL attestation.
6. Delivery: result/log return for every execution; exact primary-payload binding, terminal-state digest and mutation seal for canonical host commits.

Manifest is navigation authority. Runtime descriptor describes generated artifacts only after startup navigation. Deterministic runtime constrains truth and persistence, not the model's intellectual plan.
