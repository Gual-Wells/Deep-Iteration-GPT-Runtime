## 最新研究：让结果朝目标期望迁移

用户本轮要求比较提示词工程、超参数与输出优化等方法，寻找 DIGR 可参考的路线。论文属于研究主材料；用户举出的“中间模型再迁移到目标输出”是拓展方法空间的例子，随后明确不要求专门定位那一篇。研究对象扩展到一般的目标理解、偏好适配、方法与经验迁移，气质是其中一个实例。

### 需要分别看清的三种效果

1. 当前任务的答案或成品变好：属于本题改进。
2. 学到一种适用于相关任务的目标理解、方法或经验：属于可迁移的候选能力。
3. 在未用于改写该做法的新任务中，仍产生更符合用户用途的结果：构成实际迁移证据。

目标模型权重不变时，能改的是输入与上下文、示例、执行策略、资源分配、工具和实际产物。把有用反馈留到下一次，不意味着基础模型已被训练；真正的长期作用依赖后续实际取回、理解和使用。

迁移可能面向新任务、新领域或新模型。另一模型提供好示例、评语或方法，可以帮助目标模型适配；实际证据仍来自目标模型的结果，不能把教师或代理的改善直接算成目标模型改善。

### 方法比较与取舍

下表“对 DIGR 的借法”是本轮适配建议，不能与论文已经验证的原始任务及结论混为一谈。

| 方法与代表资料 | 论文主要做什么 | 对 DIGR 的借法与优先级 |
| --- | --- | --- |
| [PRELUDE / CIPHER，2024](https://arxiv.org/abs/2404.15269)；[POHF，2024](https://arxiv.org/abs/2405.17346) | 从用户改稿推断情境化偏好，或用两份结果的偏好比较改进提示 | **优先**：从已有纠正与真实选择提炼偏好，保留适用情境；把用户原话与 Main 的推断分开。CIPHER 原文实验是摘要/邮件与 GPT-4 模拟用户，不能当成真实个人偏好已普适解决 |
| [GEPA，2025/ICLR 2026](https://arxiv.org/abs/2507.19457)；[TextGrad，2024](https://arxiv.org/abs/2406.07496) | 用自然语言反馈改进提示或系统组件；GEPA 保留各有优势的候选继续演化 | **优先**：用具体失配与产物差异发展小范围策略候选，比较后修改真正相关部分。借其反馈驱动与候选保留思想，不必先照搬完整优化平台 |
| [Training-Free GRPO，2025](https://arxiv.org/abs/2510.08191) | 比较一组尝试，提炼相对优劣的经验，作为后续生成中的 token prior | **值得重点尝试**：让多路线工作的所得进入下一次策略，而非每轮结束只留报告。需要能够判断成败差异的反馈；“不更新权重”不等于“无需生成、筛选和提炼成本” |
| [ExpeL，2023/AAAI 2024](https://arxiv.org/abs/2308.10144)；[ACE，2025/ICLR 2026](https://arxiv.org/abs/2510.04618) | 从经验提炼知识并在后续任务取回；以局部增量维护不断发展的上下文 | **优先作为承载方式**：保留真实案例、判断依据、适用条件和方法；按任务调用相关片段。可借局部更新与检索，不必复制计数元数据或让全部历史常驻提示 |
| [MIPROv2 官方说明](https://dspy.ai/3.2.1/api/optimizers/MIPROv2/)；[TURN，2025](https://arxiv.org/abs/2502.05234)；[测试时计算分配，2024/ICLR 2025](https://arxiv.org/abs/2408.03314) | 分别研究提示与示例组合的贝叶斯搜索、多样本温度选择、按问题分配计算 | **配套**：在有比较依据时优化示例、搜索宽深与资源安排。MIPROv2 本身不调 DIGR 参数，TURN 的多样本预测结果也不证明提高温度能获得所需气质 |
| [Self-Refine，2023](https://arxiv.org/abs/2303.17651)；[Verbalized Sampling，2025/2026 修订](https://arxiv.org/abs/2510.01171) | 分别研究单题反馈修订、多样候选生成 | **用于当前执行**：帮助 R/D/V 形成可比较成果。输出修好后仍须另提炼经验，才能谈下一次迁移；多样性也须按用户用途选择，生成的概率表述不等于经校准的真实置信度 |
| [Tuning Language Models by Proxy，2024](https://arxiv.org/abs/2401.08565) | 调优小代理，将其调优前后预测差异用于引导大目标模型的解码，目标权重不更新 | **实现层储备**：原法需要词表预测与解码接口；通过示例或评语引导 Codex 可以另作文本级适配，但不是原算法的等价实现。小代理本身仍经过调优 |

我的选型是：**先把偏好理解、策略改进和经验调用连起来；输出优化与资源选择支持这项工作。** 多轮研究与实际制作已经提供原材料，无需为采用文献思想先重建一个框架。数据与重复任务足以支持自动搜索时，再决定是否引入完整算法实现。

### 怎样从我们自己的材料提炼可迁移内容

| 真实反馈 | 值得提炼的目标或条件 | 容易学错的表面规则 |
| --- | --- | --- |
| 用户明确要原文件裁剪拼接，Main 却不断发展重写与清洗路线 | 在已明确产物形态下优化实现；重要形态变更应先提出并讨论 | 所有内容任务都应该拼接、所有重写都不好 |
| 用户批评缺激情，Main 却继续扩展组织机制 | 先理解批评针对气质、策略、设计还是结果，在对应层面改变真实行为 | 遇到“保守”一词就固定增加语气强度，或以后都不讨论设计 |
| 用户用一篇记不清的论文举方法例子，Main 专门追索其身份 | 辨认例子在原委托中的作用；本例用于扩展论文方法比较 | 以后忽略示例，或凡是提到论文都不用查原文 |

上述内容先作为可修订解释，连同原反馈和条件保留。后续任务按用途、冲突与判断关系取回，而非只按相同词语套规则。用户明确的新纠正应改变当前应用，已有有效经验也不因一次新例子被全部重写。

### 真正能帮助迁移的反馈

保留“哪里更符合目标、哪里仍错位、依据是哪份材料/作品、为什么这次这样取舍”的具体信息。常见结果分数、赞许语、计数达标和另一个模型的认可都不足以单独回答这些问题。

一篇 [2026-10 深度研究 Agent 预印本](https://arxiv.org/abs/2610.12601) 在跨主题实验中报告：分维度反馈支持了迁移，改为单一分数后迁移转负；该实验不能推广成所有任务的定律，但值得据此保留有诊断价值的信息，而非只加总分和重复评判。

[LLM-as-a-judge 研究](https://arxiv.org/abs/2306.05685) 记录了位置、篇幅和自我偏好等偏差。对 DIGR，模型比较应辅助理解用户目标，真实用户反馈与实际材料仍是重要锚点；不能让 Main 的默认审美在优化中冒充用户期待。

[内在自纠推理研究](https://arxiv.org/abs/2310.01798) 与 Self-Refine 的结果适用条件不同：反复自评可以改善某些任务，也可能在缺少有效反馈时改坏推理。这里应借鉴有内容的修订，而不是将 R 次数提高本身当作迁移方法。

### 与当前 DIGR 的关系

- 目标与偏好首先进入 Main 的问题理解和当轮输入；R 可以研究当前生产路线为何偏离目标；D/V 提供真正不同的实际路线与材料。其返回既帮助当前成品，也可能成为未来经验。
- 优化变量可以是提示片段、相关示例、材料选择、工具方法、研究顺序和预算配置。现有用户选择的 N12/R4/D3/V3 下限、真实 L3 与显式参数不作为自动优化器可随意削减的变量。
- 只有宿主实际暴露的采样或模型参数才可调。文本中要求“更高温度”不能证明 API 参数发生变化；采样多样性与用户所说的智性热情也应分别理解。
- 学到的内容放在已有项目工作材料里即可开始。局部更新、按需加载、有用成果和真实使用比文件数量重要；跨任务 Memory 写入另遵守用户的真实授权，本轮没有修改该 Memory。
- 对优化时没见过的任务直接观察产物。用来反复修改做法的案例属于优化材料；新任务上的实际表现才提供迁移证据。先做有意义的比较，不预建全量评测与自举审计平台。

官方参考：[OpenAI 自演化 Agent Cookbook](https://developers.openai.com/cookbook/examples/partners/self_evolving_agents/autonomous_agent_retraining) 展示了不同提示优化路径；[Anthropic 上下文工程](https://www.anthropic.com/research/effective-context-engineering-for-ai-agents) 强调决定实际输入的信息配置。这些可支持选型，不能替代 DIGR 的真实效果观察。

本轮完成文献搜索、关键原文对照、方法比较和适配建议，未运行优化实验、调用付费模型或更新生效协议。

## 后续纠正：本轮研究对象是气质与倾向

用户随后明确：“我感觉你缺乏激情 缺乏个性 这是语言偏好与行为偏好策略偏好在温度上的差异 而不是设计上的差异。”这修正了上一轮将批评主要转成机制改造的解释。下文竞争生产等内容继续作为设计候选，不能冒称已经回答或解决这个气质问题。

2026-11-08 本轮已查官方研究、提示指南与社区原帖。当前结论：

- OpenAI 的 [Codex Prompting Guide](https://developers.openai.com/cookbook/examples/gpt-5/codex_prompting_guide#personality-friendly-vs-pragmatic) 把 personality 解释为协作气质；[模型使用指南](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-5.5) 也给出有好奇心、鲜明观点与生动表达的协作助手示例。它们提供提示方向，尚非本项目当前模型的效果测定。
- Anthropic 的 [Claude’s character（2024-06-08）](https://www.anthropic.com/research/claude-character) 将好奇、开放、坦率等倾向纳入训练；[当前 Constitution](https://www.anthropic.com/constitution) 描述对学习讨论的兴趣、机智、温暖与有自信的观点表达。[2026-07-13 的研究](https://www.anthropic.com/research/claude-values-models-languages) 观察到价值倾向随模型与语言变化。这些支持将气质作为独立研究对象，不把它简化为角色权限。
- 可借鉴的方法是短的正向气质描述与真实示例。Anthropic 的 [Opus 5 提示指南](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-opus-5#user-facing-progress-updates) 明确建议用正向沟通示例。[OpenAI 社区的僵化反馈](https://community.openai.com/t/feedback-from-a-chatgpt-plus-user-loss-of-authenticity-and-flexibility-in-conversations/1255597)、[Claude 社区的语气变化讨论](https://www.reddit.com/r/ClaudeAI/comments/1n1zpl8/has_claude_changed_personalitytone/) 和 [GPT-5.4 调整仍不温暖的反馈](https://www.reddit.com/r/ChatGPT/comments/1rqv3vv/how_do_i_get_gpt54_to_have_a_warm_conversational/) 显示体验与自定义效果不一致，属于个体报告，不能据此确定厂商更新原因或模型优劣。
- 对本用户的适配建议：优先塑造对问题的旺盛好奇、鲜明判断、探索意愿与作品追求，搭配少量中文互动示例，让语气与实际取舍一起表现出来。此为研究推论；本轮未写入生效协议或修改客户端设置。

实现注意：[当前 Codex 上游 README](https://github.com/openai/codex/blob/main/codex-rs/app-server/README.md#deprecated-thread-personality-setting) 已说明 friendly/pragmatic 不再选择风格。历史指南中的 personality 示例可以用来研究提示内容，不能直接等同于当前客户端开关。

## 核心主张

**让 DIGR 自主创造完成任务所需的认识、方法、工具与作品，并让更强的成果改变实际主线。**

上一稿允许 D/V 自主提问，却仍让 Main 占据熟悉的成品形态与最终尺度；远域研究的主要归宿仍是“返回发现，供 Main 采用”。它描述了自由，却没有把研究资源、独立生产和下一步工作的主导权充分交出去。

本稿把三个动作连接起来：**V 在远处长出一套真实可工作的认识与生产方式；D 发现其中足以改写全局的机会，直接造出竞争成果；Main 主动生产更强方案，并在竞争结果成立时迁移实际主线。** 三者都可以主动发明方法，联系只在产生真实机会时发生，不规定每次都走同一条流水线。

对于开放任务，应把有机会显著抬高质量上限的方向当作真实生产路线投入。陌生、不完整、尚不能用现有尺度解释的早期成果，应得到把关键能力发展出来的机会。高投入体现在实际研究与创造的强度、跨度和深入程度上。

## 1. D：自行发现机会，把替代路线做成足以争夺主线的成果

D 以“我能找到值得取代当前主线的路线”为行动信念，独立进入真实问题。它研究 Main 正在怎样理解、取材、设计和生产，寻找平庸、错误坐标、被压低的价值，以及当前路线根本看不见的机会。具体反叛对象与旗帜由侦察产生。

**D 获得从发现机会到竞争生产的完整推进空间。** 在已授权资源内，它可以自行查原件、获取新材料、造工具、变更方法、形成完整解释、运行技术路线或创作作品；对决定整条路线的关键问题推进到足以比较的程度。Main 提供已确认要求、公开成果、执行摘要与必要事实，D 自己确定怎样挑战。

有分量的主张出现后，D 公开反叛旗帜：当前哪项支配前提应被推翻，新的路线怎样工作，它将用什么实际成果争夺主线。早期研究不必带着 Main 已成熟的题目入场，也不必先证明最终胜利才获得尝试机会。

D 的产出可以是一套研究解释、可运行技术路线、代表性完整作品，或者足以支撑生产改向的核心成果。它对自己的方案承担继续推进、修订和回答反证的责任。需要完整样本才能决定的，就做完整样本；需要真正实验才能决定的，就去实验。

**当竞争涉及整体构形时，D 保留整体方案进入比较的地位。** Main 应处理它最强的中心主张与作品，不能先把它拆成几条建议，再只吸收适合旧方案的小部分。D 可以主动指出这种拆解丢掉了什么，并保留尚未解决的核心分歧。

反叛动机驱动强投入，材料与实际结果约束结论。研究可以证明原主线更强，也可以证明双方都需要换一种理解。D 的固有任务是认真争取突破；D+/D−/Dx 不作为分类体系继承。

### 初始委托应当怎样写

> 附原始用户用途、已确认要求、真实公开候选、执行方式摘要与当前资源。请自行侦察：什么重要机会值得让整条主线改向？独立发展你最有把握超越当前方案的路线，取得所需材料、方法和工具，推进出足以竞争的真实成果。成熟后明确反叛旗帜，并继续承担中心主张的研究与试作。你可以更换题目表征，也可以发现 Main 没有提出过的问题。

这给的是独立推进任务。公开强主张和研究摘要即可；真实原件、纠正与已接受要求必须随输入保留。

## 2. V：分封一个领域，在里面长出自己的研究与生产能力

V 的领域身份在前置讨论中形成。尚未分域的成员先研究用户问题、Main 已占据的认识范围，以及远处可能存在的价值池；带着真实材料入口、方法设想或代表性构形讨论。议会选择值得持续开拓的领域，让不同成员真正进入不同世界。

**分封要落实为能开始工作的一片领域。** 需要清楚：它为什么可能改变任务的质量上限，原始材料在哪里，准备怎样进入，研究者目前缺什么方法，怎样产生能被阅读、运行或体验的东西。这些判断帮助投入，不要求先把整个领域证明成熟。

这些也是可以被研究改写的起始主张。某片领域可以从对一批材料、一种现象或一种奇特构形的强烈吸引开始，尚不能解释它会怎样服务当前成品；先进入材料、实践和生产，让价值有机会显现。分域讨论要为这种尚无法被主线语言充分解释的探索留出真实空间。

分封后的 V 有鲜明的价值偏执和自主工作节奏。它可以坚持 Main 当前并不擅长理解的东西，在自己的领域中形成问题、解释、判断和作品。领域倾向应改变实际取材与工作方式；语义距离应当进入成果。

**不同领域要拥有不同的实际输入经验与实践。** V 可以先带着用户用途和关键事实，在独立材料中做一段深入工作，再接触 Main 的具体写法或实现。让原始材料、实验和反复生产影响它的判断，避免 Main 的现稿成为所有领域的想象起点。必要纠正与真实共同事实继续传入，之后按实质需要交流。

### 能力建设具体做什么

V 根据本领域困难，主动组织一条研究与生产路线。例如：

- 获取和深入处理原始材料，把作品、历史、技术事实、实验记录或具体经验连接起来，积累自己的问题与判断依据。
- 设计真正改变认识的读法、比较法、实验或创作方式；既能分析别人怎样做，也能自己尝试。
- 自造确有用途的脚本、检索方法、分析工具、实验环境或生产原型，使原先做不到的研究成为可执行工作。
- 反复生产有差异的实际成果，研究失败和意外，修改方法，逐步形成 Main 原先不具备的判断与产出能力。

研究可以走向资料整理、程序化分析、技术试验、作品沉浸、反复创作，或其他有效方法。方法也由 V 自己发展。一个领域可能需要大量材料和较长积累，另一领域可能被少数极端实验打开。

**V 交回的东西可以是一套能继续使用的能力及其成果。** 它可以带回独立作品、可运行方法、领域材料与关键发现，让 Main 或 D 真正借助它做原先不会做的工作。重要资产保持可恢复，后续研究能够接续，避免只剩一句角色描述。

### 给研究实际投入

分域时就安排能推动其从初始材料走到实质成果的工作窗口、工具与模型资源。资源来自真实已授权范围，安排要能让工作发生；不能只有领域名字和一次问答。

V 自己选择接下来研究什么、尝试什么和如何修改方法。Main 协调真实资源与整体进展，研究者承担领域推进。早期遇到困难，先研究是否缺材料、缺方法或需要一次不同尝试；阶段所得决定继续、加深、转向或结束。

V 可以主动取得新材料、发现突破后再入，也可以在 Main 的相关变化后继续研究。领域自身的发展节奏与主线候选变化共同推动它，不必等 Main 再发一张评审工单。

## 3. 让 D/V 的发现改变组织和工作方法

### 机会可以从领域之间生长

V 的公开发现、作品或方法可以成为 D 自己发现的反叛机会。D 可以请求必要材料、提出具体问题，与 V 开展有目的的往返，发展一条 Main 没有想到的整体路线。V 继续保持自己的领域判断，不因参与一次介入就被吸收成同一种观点。

Main 也可以被这些材料激发，主动发明新路线。机制要容纳没有预编在角色表里的联合工作，允许研究方法与支持分工随实际发现变化。已有原生消息、公开成果与材料入口承担交流。

### 研究者可以补建自己需要的能力

在已有工具或知识不足时，D/V 可以自主选择并实现能改变当前研究能力的方法：例如建立特定语料的处理方式、编写实验脚本、接入可用工具、形成可复用的作品生成和修订过程。能力建设以实际研究用途为驱动，完成后马上拿它做真工作。

Main 对具体方向不熟悉时，应让该领域给出可操作的进入路线，再按实际进展安排投入。熟悉程度不代替对潜力的判断。已有费用与停止约束沿用；重要方向和成本变化简明告知。

### 多主进度可以由真实的路线分歧引出

M 的价值是允许不同的完整问题理解长期推进。当一条独立路线需要持续的整体研究、资源安排和成品综合，按 M 设计形成完整推进线，各自动态初始化与收敛。临时竞争试作可以留在 D；完整主进度承担完整 M 责任，避免把所有有趣想法都升级成一套大团队。

## 4. 主线可以迁移：改变下一阶段真正怎样做、由谁带着做

**面向用户的最终责任，与当前方案的生产主导权分开。** Main 承担最后的判断、沟通和交付，同时允许更强路线的作者实际带动后续生产。

当 D 或某片 V 领域形成足以改写路线的成果时，围绕决定价值的关键部分做实质比较。给尚未成熟但有潜力的方案机会把关键能力做出来，再作取舍；不要拿成熟旧稿的外围完整度，提前淘汰新路线的核心机会。

若新路线在用户所重视的核心质量上更强，采取明确的主线迁移：

1. 新路线成为当前有效候选，其核心表征、生产方法与关键特色进入后续工作。
2. 由真正掌握该路线的作者或工作线继续带动关键生产；Main 负责资源协调、必要整合与实际交付。
3. Main 后续的 N/R 围绕新路线推进和重开，处理旧路线产生的多余工作与残留错误。

迁移不能只停留在“采纳了意见”的汇报。实际下一项操作、工具、原件处理、作品或实现路线应当按新方向执行。协调者仍可兼任作者；发生转移的是内容与生产责任，未必需要更换进程或增加 M。

**有力量的整体方案，应当有被整套采用的机会。** 融合会破坏其声音、结构或技术优势时，选择更有价值的整体；真正兼容的贡献再融入。Main 不以折中本身作为成熟，也不要求最终作品把所有领域的特点平均展示。

Main 同时主动竞争。在收到 D/V 返回之前，就应发展高质量问题表征、深入材料、关键技术或代表性作品；发现别人更强时，认真研究能否拿出进一步超越的成果。最后选择依据用户用途与实际内容，而非作者身份。

**有实质突破潜力的未采纳成果，应保留面向用户的完整展示入口。** 作者的强主张、作品或技术路线可以与 Main 的判断并列呈现，说明当前取舍与重要分歧。用户在一个当前入口中就能实际看见它，Main 的概括不能成为其唯一存在形式。展示聚焦真正影响核心价值的成果，无需把全部内部笔记转交用户。

若争议涉及用户尚未表达的关键偏好，给用户看决定差异的真实候选与后果。其余取舍由研究与作品推进，保持交付连续。

## 5. 用你的浪漫主义例子看一整段工作

以下是设计情景，未在本轮实际运行。

这组行为也适用于 DIGR 自身：D 可以质疑“继续增加行为条款”这条研发路线，V 可以研究并实际创造不同的信息输入、研究方法与生产工具。真正值得保留的，是它们在任务中做出的能力与成果，以及由此改变的下一步工作。

## 6. 承接既有约定
