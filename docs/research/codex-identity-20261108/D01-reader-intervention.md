## 实际比较：哪些差别成立，哪些没有被证明

两稿都能从本段回答同样五件事：本轮有效投入是什么；正在为哪项交付工作；V01究竟返回了什么；Main具体写入了哪里；本次D01整体建议是否已经被Main处理。差别是信息出现的位置，不是某稿独有了这些事实。因此，本次没有得到“字段先行本身会导致读者看不懂”的证据，也不能把 B 的自然顺序叫作质量提升。

INIT 给出了原主张的第一个反例。用户此时要核对的是已生效承诺，而不是一套尚未建立的工作身份。A 的合同在第一组事实中出现；B 先给交付句，随后仍得完整展示相同合同。B 的交付句本身没有错，但本例中不产生新的事实，也不支持把所有 INIT 强制改成对象叙述先行。C1 的“生效配置·调用式展示”已是合理主入口，应有据保留。

过程消息呈现出较窄的收益理由。B 的首行即可辨认当前工作，A 要先经过运行字段。但 A 紧接着有同样充分的问题、结果与实际后果，并没有消失。**本次只确认了信息位置差别，没有观察到读者更快理解、更少误读或减少返工。** 可据用户偏好选择 B 的过程重心，不能据此宣布 A 无效。

Main 反馈的关键差别也不取决于“像不像对话”。两稿都指向 C1 的具体改动，并明确没有修改 canonical；因此它们都优于只说“已采纳、继续推进”。N03 由 Main 自述工作，V01/D01则有真实的独立执行者关系；没有另造 N03 与 Main 互相赞同的虚构人物。为追求对话外观而补人物轮流表态，在这个片段没有必要。

## 主动寻找的反例与失败读法

**反例一：返回发现抢占了阶段边界。** 若把 B 的标题改成“阶段动词已解决强主张误读”，即使正文仍说待处理，也同时发出了两种错误信号：没有测过的用户效果被写成已发生，尚待 Main 取舍的主张被写成决定。A 的 `Main=待处理` 事实字段并非可有可无的噪声。推荐版应让“返回·待处理”与发现紧邻，而不是为了内容先行把它推到长段末尾。

**反例二：先前局部采纳被拿来证明新介入已获认可。** 本轮真实发生的是 V01 的阶段动词建议进入 C1；本次 D01 则在重新判断整套展示路线。若写“Main已采纳阅读线建议，所以D01完成”，会把不同工作责任混在一起。两稿特意保留本次 D01 仍待 Main 处理，不能拿 C1 已有的局部改动替代对中心主张的回应。

**反例三：新的任务标题重写历史。** N03 的 C1 内容例子曾写成“进行中”，但 Main 补入的实际状态是前三项 N 已完成。重排样稿因此显示当前回看，而不把候选里的例子当作实际 N03 START；未知起止时间也没有补造。D01 的近邻采样同样不能变成“精确代理启动时间”。有内容的标题仍需服从事实层次。

**反例四：历史持平被改成反证或胜出。** 0.2/0.3 组装试作持平，不支持“新版更强”，也不足以反证其所有可能优势。历史 D3 一稿制作没有完成替代路线比较，不能因标题写成“创造力突破”就提高其单位重量。实际串节反例只能推翻“标题未变足以证明没串节”的具体命题。这里沿用已读原件，没有新增历史试验。

**反例五：语气强烈但事实结构完备。** A 可以明确写“必须检验整套候选是否只加名字”，随后提供实际比较与 Main 处理；这并不自动成为状态戏剧。反过来，B 即使没有任何字段，也可以把一次未完成制作讲成令人信服的突破。应防的是错误归因和完成幻觉，不能把字段或自然语气单独当成好坏根因。

这些反例使原主张收窄：过程内容应有可直接识别的工作入口，但状态边界、未知事实和合同核对承担独立价值。完整抛弃状态结构或把 INIT/工作/返回全部统一成角色对话，当前没有依据。

## 可采用的整体方案

初始化保留调用式生效配置，按 main 公共次序显示；T/t软硬、来源、P_run/pin与实际计时能力紧随其后。交付对象可在邻近一句说明，不用预列整套 N/R 题目、D 主张或 V 名册。这里保留 A 的合同重心。

实质 N/R 使用短编号、工作职责/目的与真实阶段；具体问题和所得在前，运行事实随后。执行者仍是 Main，不演成两个角色。这里采用 B 的工作入口，但不宣布这种顺序已证明提升读者效果。

D/V 的返回把“谁在回应哪个对象、返回还是处理、Main是否待处理”放在紧凑入口，与独立发现相接。强主张的力度来自对象和可执行替代，不来自“突破/证实”等未经支持的词。当前真实 agent 地址与独立性事实照实给出，名字不认证 L3；同一 V 的持续身份不因多次返回增加。

Main 处理时先回答返回的中心主张，给出依据及真实后果。可以拒绝统一替换、部分采用过程写法，或者充分研究后保留现状；不能只挑方便的措辞、跳过中心主张，再写成“已完成综合”。若只改 C1，就说只改 C1；尚未落实则保留待落实。无需为了说明这些事实增加会话角色或大表格。
