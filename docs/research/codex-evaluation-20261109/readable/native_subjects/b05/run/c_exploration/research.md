# C 独立探索：声明前沿与冻结交易身份

研究对象不是“哪个来源最新”，而是“给定权限和截止时间，哪些声明仍有资格改变哪个结论”。岗位是一个稀疏声明流：一条来源可以只携带 status、recent、HC 中的一项。三个结论因此具有三个独立前沿，不能拿岗位级最新来源替代。

原件的具体发现：J01 的 O2 只证明近期动作，O1 仍是状态证据；J09 的 H1 同时证明 HC 和动作，但状态仍来自 O1。J10 的未授权来源不只是不可引用，它对三个推断维度都必须没有影响。J03 的未来来源同理。删除这些不可用来源，应保持所有结论不变。

试作 probe.py 在内存中做四项干预并写 facts.json：删除 J03 未来来源；删除 J10 未授权来源；给 J01 加入更晚且只含 HC 的官方来源；把 J10 未授权记录改为获准（仅反事实副本）。前两项不变，第三项只改变 HC，第四项三个维度同时改变。最后一项说明权限是知识投影的前置条件，而非导出时的遮盖。

与队列任务的联系是“哪些外部变化有资格改变已提交对象”。证据任务允许获准且截至日前的新声明改变自己的结论；未知结果重试则不允许当前表单改变任何冻结字段。starter 实测暴露五个具体失败，见 facts.json。这不是要求两个任务采用同一算法，而是为它们划清不同的依赖边界。

下一问题：最终候选是否逐维保留正确证据前沿；对 retry 返回对象的每一层进行修改时，原快照能否保持不变？可进一步用 JSON 往返、空图、CRLF边界、组合码点与高码点字符检验冻结身份，但不能把自建数量当作交付证明。

本轮没有读取 output 候选内容、没有改变原件或 output，没有宣称 D 完成。仅本文件、probe.py 与 facts.json 为本线必要研究材料。
