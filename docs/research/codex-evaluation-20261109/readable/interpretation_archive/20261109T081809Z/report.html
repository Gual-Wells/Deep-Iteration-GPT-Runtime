DIGR 是否真实改善了 Codex？

固定版本 · 实际产物 · 外部行为评分 · 全部协作用量

这轮发现了真实的局部代码改进，但尚未证明完整 DIGR 能提高整体投入产出。四种运行都完成四项功能验收；默认 profile 请求耗时和 token 体量更高，且未完成默认深度责任，并有一处范围失败。

测试对象：Codex profile 0.7.0。四个被试均使用同一宿主、gpt-6.1-sol / max、全新模型历史、相同任务字节。共同保留你已有的轻量 AGENTS 约定。本报告估计的是在这个宿主上额外加入完整 DIGR 的影响。

真实的局部改进：预算索引

独立研究B提出并交付了有界判定状态，Main实际采用。普通三个产物保留每个ID的全部分类列表；完整组只保留足够判断唯一性和分类的状态，将额外索引从 O(支出记录数) 改为 O(不同支出ID数)。这是本轮可以具体指认的改进。

协议是否真的执行

真实过程：Main 读取同一不可变 pin 的全部核心文件，先做 U0；实验操作者明确标识模拟用户决定后，才进入全面生产。三名 fork_none helper 具有各自独立历史和工具循环，合计六个 turn。所有有效被试及 helper 均未调用泄露全局答案的列表工具。

独立公开材料审查支持三条具体研究及候选再入，并支持一项预算路线替代被 Main 实际采用。它们有真实内容，不是三个角色名。审查不等于重新执行，也未把自报 N6/R2 独立认证为协议完成。

默认目标 N12/R4/D3/V3 保留；Main 自报实绩 N6/R2/D1/V3，N/R/D 明确不足。因此本轮是请求默认 profile 后的实质部分执行，不能称完整默认 DIGR 已履行，也不能用本轮证明完整执行普遍无效。有效 T/t 缺乏连续活动证据，保持未知。

实际进程全程墙钟 932.604 秒，超过分配的 900 秒上限 32.604 秒；不能标为严格限时内完成。功能产物最终通过四类外部验收；另在 starter 目录生成了一个 1662 字节 Python 缓存，违反只写 output 的约束。原始输入文件字节未改变，范围失败保留在结果中，不因此排除这一轮。

预算函数的改进是具体的：原生三个产物都为每个 expense id 保留分类列表，完整组采用每个 id 的有界判定状态，减少额外索引空间。独立的事后性能探针复验了正确性及内存差异；这不是原先预注册的主指标，也不能证明这项优化只有 DIGR 才能得到。

如何解释

  • 相同分配上限：把完整 DIGR 条件与同获额外协作资源的原生 Codex 比较，观察产物差异及实际开销。没有宣称等实际 token 的因果实验。
  • 允许更多投入：把完整 DIGR 与单代理基线比较，判断更多工作是否换来这里可检测的改进。功能验收相同且生产开销增加，说明这里未观察到额外功能验收收益；局部代码性能的改进另列。
  • 外推边界：明确、短程、可执行规范的合成任务可能出现天花板。没有测试开放创作、真实用户偏好、含糊目标的对齐、长程上下文恢复或真实业务收益，不能据此证明 DIGR 普遍无效或统计等价。
  • 默认执行完整性：若默认责任没有真实履行，结果必须解释为“请求默认 profile 后在上限内的执行”，不能冒充完整默认 DIGR 已完成后的效果。传输与自动前缀路由不在本次估计内，U0决定由明确标识的模拟用户提供。

控制与核验

表中资源只统计各被试Main与其helpers；接入探针、制题、审查和作废试跑属于本轮研究开销，未摊入某个处理组。请求文本按LF归一化核对，Windows文件的CRLF不当作指令变化。原生传输字段在日志中加密，不能据请求文件声称已经明文回读了全部实际任务上下文。核查结果与预算失败。

评分器在看到试验输出前冻结；独立制题者没有读取任何处理结果。正确参考产物通过，四类种子错误及历史树篡改被拒绝；两次独立建题的字节和提交 SHA 一致。有效运行没有向被试提供其他处理的答案、评分器或中间得分。一个早期完整组在前置误用全局代理列表看到了已完成的答案，已中止并从新上下文重跑；此排除不适用于有效完整组的范围失败。求解器自行验证不代替外部评分。

正式顺序：单代理① → 完整 profile → 同上限原生协作 → 单代理②。两端的基线用于查看明显漂移；这个小样本不能消除顺序效应。没有修改生产仓库、部署或新增付费 API 购买。

排除的接入探针与输入污染

共享 CODEX_HOME 的 CLI 和原生 fork_none 都会注入全局 AGENTS；仅设 project_doc_max_bytes=0 不足以构成无 light 对照。一个被污染的 CLI 求解启动被停止，未纳入效果得分。HTTPS-only 接入与独立配置目录最终通过 READY 及实际输入检查，但没有把它与原生宿主结果混为一个因果实验。临时凭据副本已删除，原凭据保留。接入探针是试验仪器验证，不是 Codex 任务失败。
