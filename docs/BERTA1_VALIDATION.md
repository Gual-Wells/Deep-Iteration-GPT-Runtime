# Berta1 Validation Contract

Release is permitted only when all unit tests and `tests/validate_repo.py` pass in the source tree and again after cold ZIP extraction. The builder must regenerate execution bundle, model protocol, help, personalizations, descriptor integrity, FILE_TREE and SHA256SUMS; reject caches/symlinks/path collisions; and use fixed ZIP timestamps.

New conformance cases cover canonical D/V order, flat typed parameters, duplicate rejection, ambiguity diagnostics, a qualified V with positive exclusive time, canonical V proof, all nine audit files and complete workspace recovery. Existing stable.1 tests remain the regression floor for pinned transport, exact Candidate delivery, D/L isolation, clock parity, semantic event binding and terminal recovery.
