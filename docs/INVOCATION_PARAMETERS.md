# Invocation Parameters

## N
`N` 是提示词优化的最小有效循环次数，不是“必须改 N 个版本”。无收益修改可以保留上一版，但必须完成完整检查才计数。

## T
`T` 是复杂度代理。它回答的是“如果由人类高质量完成，这个任务大致值得用多深的研究/分析预算”，不是“模型真的等待了多久”。

支持示例：`10m`、`30m`、`90m`、`1h`、`2h`、`30分钟`、`2小时`。解析器不强制标准化单位；模型按语义解释。

## 示例
- `深度迭代（3，20m）：比较两个方案`
- `深度迭代(6,1h):审查这个仓库并修复`
- `深度迭代：核实消息`（自动预算）
